# 학년도별 서버 현황 확인

학년도가 바뀌면 달라지는 값이고 학교마다 다르다. 스크립트는 이 값에 기대지 않는다(부서 번호는 매번 `AGICHO.DBF`, 아카이브는 날짜 범위로 고른다). 지난 학년도를 조회하거나 부서 칸 번호가 필요할 때 아래로 직접 확인한다.

## 서버 루트

현재 학년도 DB는 학년도 첫해 1월 1일부터 이듬해 2월 말까지의 날짜 행을 미리 만들어 둔다(약 420행). 빈 날도 행이 있으므로 실제 작성일은 `ALME` 칸이 채워진 행으로 센다.

## 아카이브

`B20xx\`·`20xx\` 폴더는 '새학년도 파일 다시작성' 때 남는다. 실측한 학교에서는 폴더명보다 한 해 뒤 학년도 기록이 든 폴더가 있었고, 몇 학년도는 빈 파일이거나 새 학년 준비 중 며칠치만 남아 사실상 보존되지 않았다. 폴더별 날짜 범위는 각 폴더 `ALIM.DBF`의 첫·끝 `ALDATE`로, 기록 일수는 `ALME` 칸이 채워진 행 수로 본다(스크립트의 `source_for()`·`count_filled()`와 같은 방식).

## 부서 칸 번호

`AGICHO.DBF`의 `ALID`(칸 번호)·`ALBU`(부서명)가 정본이다. 실측한 학교는 교장·교감, 업무 부서들, 학년부, 행정실 순으로 15칸을 썼다. 급식지도 배정표처럼 날마다 올라오는 공지는 관행으로 특정 부서 칸에 붙으므로, 처음 쓸 때 몇 날짜를 `--stdout`으로 훑어 어느 칸인지 확인해 둔다.
