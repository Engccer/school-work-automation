# 알림장관리 3.0 앱 구조 (2026-09-28 조사)

## 프로그램

- 설치: `C:\알림장\ALIM.EXE`(2,395,648 bytes, 2021.01.09 빌드) + `ALIM.DLL`, `Ace32.dll`, `DrPrint32.dll`. 제거 정보는 레지스트리 `HKLM\Software\WOW6432Node\...\Uninstall\알림장3`에 있다.
- 기술: xHarbour 0.99.61 + FiveWin(창 클래스 `TWINDOW`·`TBAR`·`TBTNBMP`·`TMSGBAR`, 자체 컨트롤 `DRCALEND`·`TDRBTNBMP`·`TDRIMAGE`·`TDRANI3`), DBFCDX 드라이버. 32비트.
- 서버 경로 `\\관리자\$ALIM$\`는 실행 파일에 하드코딩되어 있다. 다른 학교 이름도 여러 개 들어 있어, 여러 학교에 배포된 개인 제작 프로그램으로 보인다.
- 주 창 제목은 `** 알림장3.0 **  /만든때 : 2021.01.09`, 날짜별 입력 화면은 제목 없는 `#32770` 대화상자다.
