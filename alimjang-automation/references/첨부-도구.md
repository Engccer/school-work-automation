# 첨부 읽기 도구 선택과 연결

알림장 조회·검색·전달사항 저장·첨부 원본 복사에는 문서 변환 도구가 필요하지 않다. 첨부 내용을 읽거나 요약할 때만 해당 형식의 도구를 준비한다. 이미 사용할 수 있는 도구가 있으면 추가 설치하지 않는다.

## 도구 선택

| 읽을 형식 | 도구 예시 | 범위 |
|---|---|---|
| HWPX | [hwpx-tomd](https://github.com/Engccer/hwpx-tomd), `pip install hwpx-tomd` | HWPX 본문·표를 텍스트로 추출. HWP 직접 읽기·OCR·편집은 지원하지 않음 |
| HWP·HWPX | [hwpx-automation](https://github.com/Engccer/hwpx-automation) 또는 해당 형식을 읽는 다른 도구 | 선택한 기능에 필요한 하위 도구도 해당 설치 안내에 따라 준비 |
| PDF·XLSX 등 | 해당 형식을 읽는 도구 | 대화형 작업에서 에이전트가 쓸 수 있으면 활용 |

특정 스킬 설치는 필수가 아니다. HWPX 읽기 도구만 준비된 상태를 HWP까지 지원하는 것으로 보고하지 않는다. 도구가 없으면 해당 첨부는 파일명·미처리 사유와 함께 원본을 보관하고 다른 작업을 계속한다.

## 예약 자동화 연결

예약 실행은 대화 중 도구를 탐색하지 않고 `scripts/extract_attachments.py`에 연결된 경로만 사용한다.

- HWPX: `ALIM_HWPX_CMD` → `hwpx-tomd` → 기존 `hwpx-automation`의 읽기 명령 순으로 선택한다.
- HWP: `ALIM_HWP_CMD` → 기존 `hwpx-automation`의 HWP→HWPX 변환 후 HWPX 읽기 경로로 처리한다.
- 기존 스킬 호환 경로는 같은 스킬 폴더의 `hwpx-automation` 또는 `HWPX_AUTOMATION_DIR`다. 이 HWP 호환 경로에는 `convert/hwp2hwpx.bat`와 JDK 21이 필요하다. 다른 도구를 선택했다면 그 도구의 요구사항을 따른다.
- PDF는 `pdftotext`, XLSX는 `openpyxl`(`pip install openpyxl`), ODT는 기본 XML 추출을 사용한다. 이 도구들도 해당 첨부 읽기에만 필요하다.

다른 한글 도구를 자동화에 연결하려면 해당 형식의 환경 변수에 **명령과 인자의 JSON 배열**을 지정한다. 도구 또는 작은 연결 스크립트는 입력 파일을 읽어 UTF-8 텍스트/Markdown 출력 파일을 만들고 성공 시 0, 실패 시 0 이외의 종료 코드를 반환해야 한다.

```powershell
# 이미 준비한 변환 스크립트의 경로·옵션에 맞춘다.
$env:ALIM_HWP_CMD = ConvertTo-Json -Compress -InputObject @(
  'python', 'C:\문서도구\read_hwp.py', '{input}', '{output}'
)
```

`ALIM_HWPX_CMD`도 같은 형식이다. `{input}`과 `{output}`은 각각 원본과 출력의 절대 경로로 바뀐다. 인자를 공백으로 나누거나 셸 문자열로 실행하지 않는다. 실행 파일·스크립트 경로는 작업 스케줄러에서도 찾을 수 있게 절대 경로를 권장한다. 실행 파일에 `.cmd`·`.bat` 래퍼는 지원하지 않는다. 위 `$env:` 설정은 현재 프로세스와 자식에만 적용되므로 예약 실행 프로세스에도 같은 설정을 전달한다.

```powershell
python scripts/extract_attachments.py --check-tools
python scripts/extract_attachments.py "<대표 첨부를 모은 폴더>" "<별도 출력 폴더>"
```

첫 명령은 설치·변환 없이 연결 후보만 확인한다. `candidate`는 실제 문서 검증 완료를 뜻하지 않는다. 두 번째 명령으로 대표 HWP·HWPX를 각각 확인하고, 본문·표·숫자 및 그림 속 글자 처리 범위가 목적에 맞는지 검토한 뒤 예약 실행에 사용한다. 환경 변수가 잘못 설정되면 다른 도구로 조용히 우회하지 않고 설정 오류를 보고한다.

## 결과 해석

- `OK`: 텍스트 추출 완료.
- `WARN`: 텍스트를 추출했지만 그림·누락 등 확인할 사항이 있음. 사용자 지정 도구는 경고 전달 규약이 서로 달라 결과 검토 안내를 함께 남김.
- `SKIP`: 선택 도구가 없거나 자동 추출을 지원하지 않는 형식. 기본 정리는 계속함.
- `FAIL`: 설정 오류·변환 실패·빈 출력 등 실제 오류. 실패한 출력은 요약에 쓰지 않음.

형식별 처리는 파일마다 독립적이다. 예약 실행은 날짜 폴더에 `<날짜> 알림장 첨부 처리 결과.txt`를 남기며, 읽은 첨부만 요약하고 읽지 못한 첨부의 내용은 추측하지 않는다. 모든 첨부가 `SKIP`이면 요약 없이 기본 정리를 마친다. 실제 오류와 선택 기능 미설치는 구분해 보고한다. 도구를 준비한 뒤 이미 생성된 요약을 다시 만들려면 `run_daily.ps1 -Force`를 사용한다.
