## 저장 폴더에 같은 이름이 있으면 전송이 멈춘다

2026-10-29. 담임 여러 명의 회신 첨부를 받는데 한 건만 두 번 연속 `전송멈춤(관리함에서 재시도)`으로 끝났다.
제한 시간을 25초에서 150초로 늘려도 같았다. 화면을 보니 `같은 이름을 가진 파일이 이미 존재합니다`
창이 떠 [다시받기] [다른이름] [넘어가기] [받기취소]를 묻고 있었다. 저장 폴더(`DownPath`)가
업무 폴더 루트로 잡혀 있었고 거기 같은 이름 파일이 남아 있던 탓이다.

`Wait-CMDownload`가 `파일 다운로드 중` 제목만 찾았기 때문에 이 창을 못 보고 제한 시간을 넘겨
STALLED로 보고했고, 그 안내(`관리함에서 재시도`)대로 해도 같은 창이 또 떠 두 번을 헛돌았다.
저장 폴더의 그 파일을 옮기고 다시 받으니 한 번에 받아졌다.

그래서 `cm_save_attachments.ps1`이 저장을 누르기 전에 `DownPath`의 동명 파일을 검사해 걸러 내고,
`Wait-CMDownload`는 이 창을 만나면 [받기취소] 후 `DUPLICATE`를 돌려주도록 고쳤다.
`-Overwrite`로 [다시받기]를 누르는 경로도 넣었으나 **이쪽은 아직 실측하지 못했다**(실제로 통한 것은
저장 폴더의 파일을 치우고 재시도한 방법이다).

한편 정리 코드에서 `[CM]::Post`를 불렀다가 '메서드가 없다'로 실패했다. 창 닫기는
`[CM]::PostMessage($h, 0x0010, …)`다.

`powershell.exe -NoProfile -ExecutionPolicy Bypass -File` 경로에서는 정상 실행됐다.

## 조직도에서 한 사람에게 새 메시지 작성

2026-10-22: 검색란에 클립보드로 붙여넣은 이름이 화면에 반영되지 않아 부서를 펼쳐 대상을 찾았다.
`Invoke-CMClick`을 두 번 호출하거나 선택 후 Enter를 보내도 작성 창이 열리지 않았다.
대상 행에 커서를 두고 `mouse_event` down/up 쌍을 80ms 간격으로 두 번 보내자 열렸다.
작성 창의 받는사람 라벨과 본문 캡처를 확인한 후 발송했다.

## 발송 확인

2026-10-22: `BM_CLICK` 후 15초 대기한 첫 DB 조회와 그다음 조회가 모두 0건이고 작성 창도 남아 있었다.
이를 미발송으로 오판해 실제 클릭으로 재시도하려 했으나, 그 사이 작성 창이 닫혀 활성화 단계에서 중단됐다.
이어 DB에서 해당 메시지 1건이 확인됐다. **최초 클릭이 지연 처리된 것이며 실제 클릭 재시도는 실행되지 않았다.**
정확한 지연 시간은 측정하지 못했지만 기존 안내의 5~15초를 상한으로 쓸 수 없음을 확인했다.
0건 직후 재발송하려 한 판단을 교정해, 클릭 뒤에는 읽기 전용 재조회만 하고 제한 시간 뒤에도 불명확하면
자동 재발송하지 않도록 정했다.

## Windows PowerShell 5.1에서는 돌지 않는다

`[UIntPtr]4096` 형변환이 5.1에서 `Cannot convert the "4096" value of type "System.Int32" to
type "System.UIntPtr"`로 죽는다. 변수든 리터럴이든 같다. `cm_lib.ps1`의 `Read-CMList`·
`Get-CMRowPoint`와 `cm_tree.ps1` 전부가 이 호출을 거치므로 5.1로는 목록조차 못 읽는다.
`pwsh`(7)에서는 그대로 통한다. SKILL.md의 실행 전제를 `powershell`에서 `pwsh`로 고친 근거다.
(2026-10-28 실측)

## 조직도 개별 발송에서 새로 안 것

- 작성 창(`메시지 전송 (크롬에디터)`)은 **손대지 않으면 저절로 닫힌다.** 조직도 더블클릭으로
  열어 두고 다음 호출에서 채우려 했더니 창이 이미 없었다. 열기·제목·본문·첨부를 한 번의 실행에서 끝낸다.
- **제목(`Edit` id=4362)은 붙여넣은 뒤에도 `GetWindowText`가 빈 문자열을 돌려준다.**
  캡처에는 제목이 보이고 `tbl_send.Title`에도 정확히 들어갔다. 비었다고 다시 넣으면 안 된다.
- 한 사람이 조직도 **여러 곳에 중복**해 나온다(부서별, 실측 3곳). 계정 글자가 같으면 어느 것을 써도 된다.
- 화면 밖 항목은 `TVM_GETITEMRECT`가 음수 좌표를 준다. `TVM_ENSUREVISIBLE` 뒤 다시 읽어야 한다.
- 32비트 `TVITEMW`는 40바이트이고 `pszText` 오프셋 16, `cchTextMax` 20이다(ListView와 다르다).

(2026-10-28 실측)
