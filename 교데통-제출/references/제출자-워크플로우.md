# 교데통 제출자 워크플로우 상세

메뉴경로: 교데통 > 데이터취합 > 제출자료

## 접속

- **업무용 URL: `https://sen.edmgr.kr`** (시도 서브도메인). 업무포털 `sen.eduptl.kr` 인증서 로그인 후
  상단 [교데통] 메뉴 클릭 → 새 탭으로 SSO 자동 진입.
- `https://www.edmgr.kr`은 **공개 교육데이터플랫폼**으로 데이터취합 메뉴가 없다(네이버·카카오 로그인).
  업무용 진입점이 아니므로 혼동하지 말 것.
- 같은 브라우저 프로필의 새 탭에서는 `sen.edmgr.kr` 세션이 공유된다.

## 제출 절차 (단계별)

### ① 요청 확인

- 경로: 제출자료 > **기관접수대기** 탭
- 발송기관(교육청 등)이 보낸 데이터취합 건 확인
- 건수가 많으므로 상단 `요청자료명` 검색창에 키워드를 넣고 [조회]
- **이 목록은 기관(부서) 내 전체 직원에게 보이고, 누군가 접수하면 나머지 직원 목록에서 사라진다.**
  건이 안 보인다고 요청이 없다고 단정하지 말 것

### ② 요청 접수

- [접수] 버튼 클릭하여 접수
- 접수 후 내담당 탭으로 이동됨
- 데이터취합 대상이 개인으로 지정된 경우 접수 없이 바로 내담당 탭에 표시

### ③ 제출자료 작성

- 경로: 제출자료 > 내담당 탭 > 해당 건 선택
- 데이터취합구분에 따라 처리:
  - 사용자지정서식: 서식에 직접 데이터 입력 (행 추가/저장)
  - 사용자지정서식(서식+파일): 서식 입력 + 파일 첨부
  - 파일취합: 작성 완료된 파일(엑셀 등) 첨부
  - 데이터관리카드: 메타데이터 기반 입력 (별도 절차)
- 임시저장 가능

### ④ 제출

- 자료 작성 완료 후 [제출] 버튼 클릭
- 제출방법 선택:
  - 전자결재: 에듀파인(업무관리) 결재 연동 → 결재완료 = 최종 제출
  - 내부승인: 교데통 자체 내부결재
  - 바로제출: 별도 승인 없이 즉시 제출
- 전자결재 선택 시 결재라인 확인 필수

### ⑤ 제출자료 관리

- 경로: 제출자료 > 제출완료 탭
- 제출완료 상태 확인

### ⑥ 재작성(회수요청)

- 경로: 제출자료 > 제출완료 탭 > [회수요청] 버튼
- 자동회수 설정된 경우: 즉시 회수
- 자동회수 미설정 시: 요청자 승인 후 회수
- 회수 후 내담당 탭에서 수정 → 재제출

## K-에듀파인 용어 대응

| K-에듀파인 (자료집계) | 교데통 (데이터취합) |
|---|---|
| 제출요청자료 | 접수대기 탭 |
| 제출대기자료 | 내담당 탭 |
| 제출완료자료 | 제출완료 탭 |
| 공문시행 + 내부결재 | 전자결재 (통합) |
| 메모보고 | 삭제됨 |

## 결재라인 (예시)

- 일반적 결재라인: 담당교사 → 부장교사 → 교감 → 교장
- 간이 결재: 담당교사 → 부장교사 (건별 상이)
- 전자결재 선택 시 K-에듀파인에서 결재 진행

## 유의사항

- 제출기한 이후 제출 불가 → 여유 있게 결재 상신
- 강제종료된 건은 제출 불가
- 담당자 변경 필요 시: 접수 후 담당자 변경 기능 활용
- '해당없음'으로 제출 가능 (해당 건이 학교와 무관한 경우)
- 제출자료 부서 공유 설정으로 같은 부서 교직원과 공유 가능
