# 재직증명서 등 교육제증명 발급 — 정부24

목차: 1 경로 · 2 로그인 · 3 신청 폼 · 4 [신청하기]와 신청 내역 · 5 문서출력 → PDF 저장 · 6 산출물 검증 · 정부24 화면 함정

재직증명서·경력증명서·퇴직증명원은 **업무포털·나이스(내부망)가 아니라 공인망의 정부24에서**
발급한다. EVPN도 교육행정 전자서명 인증서도 필요 없고, 로그인은 정부24 계정(모바일 신분증·
간편인증·공동인증서)이다. 나이스 진입 절차를 여기에 끌어오지 말 것.

1. **경로는 둘이고 종착지는 같다.**
   - 정식: 나이스 대국민서비스(`www.neis.go.kr`) → 서비스 바로가기 **[교육제증명]** →
     온라인 민원 → **[인사]** 탭 → 재직증명서 **[바로가기]** → 정부24.
   - 지름길: 정부24 서비스 안내 `https://www.gov.kr/portal/service/serviceInfo/134200000063`
     (「재직증명서 발급(교원, 계약제 교원, 교육감 소속 지방공무원, 교육공무직원)」) →
     **[발급하기]**. 효력은 같다. 신청 화면은
     `plus.gov.kr/minwon/apply/applyMinwonForm?cappBizCd=PG4CADM0681`.
   - **나이스 대국민서비스 메인 아이콘은 자동화로 못 누른다.** 이 화면은 Nexacro라
     `서비스 바로가기` 아이콘 행이 부모 컨테이너 위로 잘려 rect가 `y=-18`로 잡히고, 페이지·
     내부 스크롤 어느 쪽으로도 뷰포트에 들어오지 않는다(그 자리는 스크린샷에 회색 여백으로만
     보인다). 버튼 객체(`btnServiceLink1`)에 onclick 핸들러도 붙어 있지 않아 JS 호출로도
     우회되지 않는다. **이 화면과 씨름하지 말고 정부24로 직행**한다.
2. **로그인은 사용자 몫**이다. [발급하기]를 누르면 `plus.gov.kr/login`으로 넘어간다
   (`plus.gov.kr` 첫 접근의 권한 거부는 SKILL.md 사전 점검 4번대로 한 번 더 하면 통과한다).
   인증 수단 선택·인증서 비밀번호·간편인증 승인은 자동화 금지 영역이므로 로그인 화면까지만
   열어 주고 사용자에게 넘긴다. 로그인 후에는 신청 화면으로 자동 복귀한다.
3. **신청 폼은 필드 4개**다(성명·주민등록번호는 로그인 정보로 자동 채워짐).

   | 필드 | 값 | 비고 |
   |---|---|---|
   | 교육청(필수) | 소속 시·도교육청 | `select` 요소라 폼 값 설정이 그대로 통한다 |
   | 주민등록번호 뒷자리(필수) | **비공개**(기본값) / 공개 | 기본값이 비공개이고 그대로 두는 것이 맞다 |
   | 용도(필수) | 예) 제출용, 기관제출용 | **증명서에 그대로 인쇄된다** |
   | 수령 방법 구분(필수) | **온라인발급(본인출력)** | 전자문서지갑 / 등기·일반·무료우편도 선택 가능 |

   - **용도는 사용자에게 확인받는다.** 증명서 본문에 찍히는 값이고 제출처가 문구를 따지는
     경우가 있어 임의로 정하지 않는다. 제출처가 특정되지 않으면 `제출용`이 무난하다.
   - **주민등록번호 뒷자리는 비공개가 기본값이자 권장값**이다. 제출처가 명시적으로 요구할
     때만 공개로 바꾼다(개인정보 최소 노출).
   - 화면 상단 안내에 **"시도교육청에 따라 발급가능 기준년도가 다르다"**, 그 이전 재직분은
     교육청·교육지원청·학교 방문 발급이라고 적혀 있다. 문의는 **나이스 중앙상담센터 1600-7440**.
   - 수수료는 없다(온라인 발급 무료).
4. **[신청하기]** → 별도 결제·전자서명 단계 없이 곧바로
   **서비스 신청 내역**(`plus.gov.kr/mypage/mbrAplySrvcList`)으로 넘어가고, 처리상태가
   즉시 **처리완료**로 뜬다. 안내문의 "이 민원은 인증서를 통한 전자서명이 필요합니다"는
   로그인 단계의 본인확인으로 충족되며 별도 서명창은 뜨지 않는다.
   - **행 하나를 확인해 중복 신청 여부를 반드시 검증**한다. 접수번호 `YYYYMMDD-…`, 민원
     사무명, 부수, 처리상태가 한 줄로 나온다. 신청 목록은 **최근 4일치만** 기본 조회된다.
5. **문서출력 → PDF 저장은 끝까지 자동화된다.** 신청 내역 행의 **[문서출력]** 은
   `window.open`으로 **별도 팝업 창**(`plus.gov.kr/ezpdfwv/viewer`, 창 이름 `prdocPopup`)을
   여는데, 그 창은 확장 탭 그룹 밖이라 직접 제어할 수 없다. 그러나 **팝업을 현재 탭으로
   끌어오면** 그 안의 pdf.js에서 원본 PDF 바이트를 그대로 꺼낼 수 있고, 네이티브 인쇄
   대화상자를 열 필요가 없다. 순서는 이렇다.
   1. 이미 열린 팝업을 정리한다 — opener에서 `window.open('','prdocPopup').close()`.
      (창 이름이 고정이라 [문서출력]을 여러 번 눌러도 창은 하나뿐이다)
   2. `window.open`을 가로채 현재 탭을 그 URL로 보낸다.
      ```js
      window.open = function(u){ if(u && u!=='about:blank') setTimeout(()=>{location.href=u},50); return window; };
      ```
      그다음 [문서출력] 버튼을 클릭하면 뷰어가 **확장 탭 안에서** 열린다.
      (`window.open`을 단순히 무력화해 `window`만 돌려주면 아무 일도 일어나지 않는다 —
      이 사이트는 form target 방식이 아니라 `window.open(url)`으로 바로 연다)
   3. 뷰어 툴바에는 **[인쇄하기]뿐이고 저장·다운로드 버튼이 없다.** 실제 문서는
      **same-origin iframe `/ezpdfwebviewer/viewer` 안의 pdf.js**가 그리고 있으므로
      `PDFViewerApplication.pdfDocument.getData()` 로 원본 바이트를 꺼내
      Blob + `<a download>` 클릭으로 내려받는다.
      ```js
      const w=[...document.querySelectorAll('iframe')].find(x=>x.contentWindow.location.pathname.includes('ezpdfwebviewer')).contentWindow;
      const data=await w.PDFViewerApplication.pdfDocument.getData();
      const a=document.createElement('a');
      a.href=URL.createObjectURL(new Blob([data],{type:'application/pdf'}));
      a.download='out.pdf'; document.body.appendChild(a); a.click();
      ```
   4. **다운로드 파일명은 ASCII로 주고** 저장 뒤 PowerShell로 최종 이름·위치를 정한다
      (한글 파일명을 `download` 속성에 그대로 넣지 않는다).
   5. **페이지 JS 실행은 async 결과를 `{}`로 돌려주므로** 위 코드의 반환값으로 성공을
      판정하지 말 것. 판정은 다운로드 폴더에 파일이 생겼는지로 한다.
   - 사용자가 직접 하겠다고 하면 팝업 창의 [인쇄하기] → 인쇄 대화상자에서 대상을
     "PDF로 저장"으로 바꾸는 경로도 그대로 유효하다.
   - 뷰어 툴바에 **점자(braille) 아이콘**이 있다.
6. **산출물 검증**: 정부24 발급 PDF는 **텍스트 레이어가 살아 있어 스크린 리더로 읽힌다**
   (폰트 5종 임베드, `uni yes`). 학교·교육청 방문 발급본이나 스캔본은 텍스트가 0이므로,
   가능하면 이 온라인 발급본으로 대체하는 편이 접근성에 유리하다.
   - ⚠ **검증할 때 `pdftotext` 출력을 터미널로 그냥 흘리면 한글이 깨져 "텍스트가 없다"고
     오판한다.** `pdftotext -layout -enc UTF-8 <pdf> <txt>` 로 파일에 뽑은 뒤
     UTF-8로 읽을 것.
   - 확인할 항목: 문서확인번호, 발급번호, 성명·생년월일·주소, 소속·직위, 재직기간과 산정
     개월수, **용도 문구**, 발급일, 학교장 명의. **주민등록번호 뒷자리를 비공개로 신청하면
     생년월일만 찍히고 주민번호는 나오지 않는다**(비공개가 제대로 반영됐는지 여기서 확인).
   - 진위확인은 정부24 인터넷발급문서진위확인 메뉴 또는 하단 바코드로 하며 **발급일로부터
     90일**까지 유효하다. 보관 파일명에 발급일을 넣어 두면 만료 판단이 쉽다
     (예: `YYMMDD_재직증명서 <이름>.pdf`).

## 정부24 화면 함정

백그라운드 창 스크린샷 타임아웃, `location.href` 차단, 팝업 창 열거(`EnumWindows`)는 SKILL.md 일반 팁
「브라우저 제어 확장 공통 함정」에 있다. 이 사이트 고유 사항:

- **정부24 버튼은 접근성 트리에는 있는데 `querySelectorAll('button,a')` + innerText 필터에
  잡히지 않는 순간이 있다**(렌더 타이밍). 버튼 조작은 요소 찾기 → ref 경로를 기본으로 하고,
  JS는 검증용으로 쓴다.
- 팝업이 열렸는지 미리 알고 싶으면 클릭 전에 `window.open`을 래핑해 URL을 기록해 두면 된다.
- **개인정보 취급**: 신청 화면에는 성명·주민등록번호가 채워져 있다. 스크린샷을 디스크에
  저장하지 않고(SKILL.md 일반 원칙), JS로 값을 읽을 때도 성명·주민번호 필드는 반환하지 않는다.
