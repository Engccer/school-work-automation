# 근무상황 신청 — 육아시간·근무시간면제 등

복무를 신청해 결재에 올리는 절차. 하루 단건도, 같은 시간대를 여러 날 반복하는 건
(육아시간·모성보호시간 등)도 같은 화면에서 처리한다. 상신 단계는 [상신-공통.md](상신-공통.md)를 함께 따른다.

1. **이전 신청 내용부터 확보할 것.** [상신-공통.md](상신-공통.md) 「선례 확보」대로 상신함에서
   결재문서명에 근무상황 유형명(예: 해당 휴가명)을 넣어 최근 **완결** 건의 상세보기를 연다.
   이 화면에서 재사용할 값: 결재선, 상신내용의 기간 표기
   `YYYY-MM-DD HH:MM ~ YYYY-MM-DD HH:MM (N일 매 시간 N분)`, 사유, 연락처, 대상 자녀 등.
2. **메뉴**: 기본 메뉴 > **복무 > 개인근무상황관리**. 조회 기간 기본값은 당월 1일~말일.
   (하위에 `육아시간신청조회`·`육아시간실적조회`가 따로 있지만 **신청 자체는 개인근무상황관리**에서 한다)
3. **[신청]** 클릭 → "근무상황신청" 다이얼로그. **기본 행 1개(연가)가 자동 생성되는 경우와,
   목록이 `Total 0` "데이터를 조회해 주십시오"로 비어 있는 경우가 둘 다 있다.** 비어 있으면
   **[행추가]** 를 눌러야 기본 행이 생긴다(누르기 전에는 하단 폼이 비활성처럼 보인다).
   행이 생기면 하단 "근무상황신청입력" 폼이 그 행과 실시간 연동돼, 폼을 고치면 위 목록 행이
   즉시 갱신된다. [행추가]를 더 누르는 것은 성격이 다른 건을 한 번에 올릴 때만.
   - 기존 건을 그대로 복제하려면 목록에서 대상 행을 선택하고 **[복사]** 버튼을 쓰는 경로도 있다.
   - 〔공식 FAQ〕 여러 건을 나눠 상신해도 **결재자는 기안 목록 체크박스로 일괄 승인**할 수
     있으므로, 결재 부담을 이유로 무리하게 한 건에 합칠 필요 없다.
4. **근무상황 분류**: 대분류(연가/병가/공가/특별휴가/대체휴무/결근/연수/기타) → 소분류.
   대분류를 바꾸면 소분류가 첫 항목으로 자동 세팅되지만, **소분류 드롭다운을 열어 항목을
   클릭해 확정**해야 하위 필드와 사용현황 표가 제대로 채워진다.
   - **조퇴·외출·지각·반일연가 → 연가 하위**(소분류 목록: 연가 / 반일연가 / 지각 / 조퇴 / 외출).
     연가 계열이라 우측 `연가종류`(금년도연가 등)가 함께 적용되고 연가 잔여에서 차감되므로,
     신청 전 사용현황 표의 연가잔여일수를 확인해 사용자에게 함께 보고한다. 조퇴는 대개
     하루 단건이므로 반복 체크 없이 같은 날 시각만 바꾸면 `0일 N시간 0분`으로 계산된다
     (조퇴 종료 시각은 그날의 근무 종료 시각으로 잡는다).
   - **육아시간·모성보호시간 → 특별휴가 하위**. 확정하면 자녀명 필드가 활성화된다.
   - **근무시간면제(노동조합 타임오프) → 기타 하위**. 확정하면
     *"근무시간 면제자로 지정된 사람만 면제시간을 사용할 수 있습니다"* 알림이 뜬다(정상, [확인]).
   - 〔공식 FAQ〕 **연가 신청 시 가용연가가 0 또는 빈 값이면** 가용연가가 생성되지 않은
     것이 원인이다. 개인 화면에서는 해결할 수 없고 **소속기관 복무담당자에게 연가생성**
     (복무 > 연가관리 > 개인연가관리)을 요청해야 한다.
   - 소분류 확정 시 위쪽 "근무상황사용현황" 표가 그 유형 전용으로 바뀐다. 근무시간면제는
     **면제기간별 부여시간 / 사용시간 / 잔여시간(`0200:00` 형식)** 이 나오므로,
     신청 전에 **잔여시간이 이번 신청 시간을 감당하는지 확인하고 사용자에게 함께 보고**할 것.
5. **드롭다운은 전부 커스텀 DIV**라 SKILL.md 일반 팁 「커스텀 드롭다운」대로 클릭해 고른다.
   시/분 드롭다운은 현재값 근처만 보이므로(기본 16시에서 08시로 가려면 위로 여러 번) 열린 리스트
   안에서 휠 스크롤한 뒤 `zoom`으로 값을 확인하고 클릭한다.
6. **날짜는 달력 아이콘으로만**(SKILL.md 일반 팁 「날짜 입력」). 시작 → 종료 순서로 설정한다.
   - **시작일자를 바꾸면 종료일자가 같은 날로 동기화**되므로 종료일을 먼저 잡으면 헛수고다.
   - 시작일 선택 직후 **같은 배치에서 종료일 달력을 열면 씹힌다**(동기화 렌더링과 충돌).
     별도 호출로 달력 아이콘을 다시 클릭할 것.
7. **하루 단건**은 반복 체크가 필요 없다. 시작·종료 일자를 같은 날로 두고 시각만 바꾸면
   신청시간이 `0일 N시간 0분`으로 자동 계산된다(예: 12:30~16:30 → `0일 4시간 0분`).
   전일(예: 08:30~16:30)은 `1일 0시간 0분`으로 잡힌다.
8. **여러 날 같은 시간대 = [일반복] 체크(핵심).** 시작일시·종료일시를 **하루치 시간대**
   (예: 시작일 08:30 ~ 종료일 08:50)로 맞춘 뒤 **일반복**을 체크하면 신청시간이
   `N일 매 0시간 20분`으로 자동 계산된다. 체크 전에는 기간 전체를 한 덩어리로 계산해
   일수가 0으로 나온다. 특정 요일만 쓸 때는 [요일반복] + 요일 체크박스.
   - 위 목록 행의 `반복 / 일 / 시간 / 분` 열이 `매 / 3 / 0 / 20`처럼 바뀌는지로 검증.
9. **나머지 필드**(전부 일반 입력이라 클릭 후 타이핑이 정상 동작한다):
   - **연락처** — 숫자만 이어서 입력하면 마스크가 `(010)0000-0000`으로 자동 정형된다.
   - **사유** — 한글 타이핑 정상. 직전 완결 건의 문구를 그대로 재사용하는 것이 안전하다.
   - **목적지** — 사유 오른쪽 칸. 근무지를 벗어나는 복무(근무시간면제·출장 등)에서 채운다.
   - **자녀명** 드롭다운 — 육아시간 필수(선택하면 우측에 총 사용일수 표시).
   - **비공개여부** — 기간/목적지/사유에 체크하면 일일근무상황에 공개되지 않는다.
10. **확인 ① → [승인요청]**: 폼을 다 채웠으면 **기간·시간대·사유·목적지(+ 해당되면 잔여시간)를
    사용자에게 요약해 확인받고** [승인요청]을 누른다 → **기안문서상신** 화면으로 전환
    ([상신-공통.md](상신-공통.md) 「확인 ① → [승인요청]」, 첫 클릭 무시 포함).
11. **결재선 → 확인 ②**: [상신-공통.md](상신-공통.md) 「결재선 조립」대로 조립하고 기안문서상신
    결재선 그리드를 직전 완결 건 결재선과 대조한 뒤, 결재선을 사용자에게 보여 확인받는다.
12. **[상신]** → "상신하겠습니까?" → [확인] → "상신을 완료하였습니다." → [확인].
    **[상신] 직후 화면이 그대로여도 정상**이다(SKILL.md 일반 팁 「확인·완료 다이얼로그」).
13. **검증**: 다이얼로그가 닫히면 개인근무상황관리 목록이 자동 갱신된다. 새 행의
    근무상황·기간·`일수/기간`(예: `3일매 시간20분`, `0일4시간0분`)·사유·목적지·
    **결재상태(상신(진행))**를 확인한다. 화면 하단 총계도 함께 갱신된다.
14. **잘못 올린 건 되돌리기·다시 올리기**: [상신-공통.md](상신-공통.md) 「6. 잘못 올린 건 되돌리기」·
    「7. 같은 내용으로 다시 올리기」. 이 화면의 `상신취소` 행 삭제는 "삭제하시겠습니까?" → [확인] → 해당 행이 분홍색으로
    바뀌고, **다시 늦게** "삭제가 완료되었습니다" 알림이 뜬다. 알림을 닫아도 목록은
    그대로이니 **[조회]로 재조회**해야 행이 사라지고 총계가 정정된다.
15. **세션 타이머 주의**: 신청 다이얼로그 안에서만 오래 조작하면 상단 타이머가 계속 줄어든다
    (폼 입력은 세션 갱신으로 치지 않는 듯). 화면 전환이 일어나면 60분으로 리셋된다.
    저장 전 입력값은 만료 시 전량 소실되므로, 남은 시간이 10분 안쪽이면 서두르거나
    확인 ①을 받아 [승인요청]까지 먼저 넘겨 화면을 전환시킬 것. 끊긴 뒤의 복구는 SKILL.md
    일반 원칙 「세션 타이머」.
