# 인증서 로그인 문제

- **"인증서 로그인을 위해 인증서 로그인용 프로그램 설치가 필요합니다" 알림**:
  업무포털·나이스 인증서 로그인은 K-Sign **KCase Agent**(페이지의 `kcaseagent.min.js`가
  호출하는 로컬 에이전트)가 필요하다. `C:\Program Files (x86)\Ksign\KCase`에 Uninstall.exe만
  남는 식으로 프로그램이 삭제·손상될 수 있고 그 경우 이 알림은 오탐이 아니다 —
  로그인 페이지 하단 [인증서프로그램다운로드]로 KCaseAgent_Installer를 받아 재설치(사용자
  수행)하면 해결된다. 알림을 닫고 로그인 버튼을 눌러도 인증서 선택창은 뜨지 않는다. → 사례
- **인증서 선택창에 인증서가 안 나타나면 만료부터 의심**: 만료된 인증서는
  선택 목록에서 자동으로 숨겨진다. 학교(교육행정 전자서명) 인증서는
  `C:\GPKI\Certificate\class2\`에 서명/암호화(sig/env) 쌍으로 저장되며, PowerShell로
  유효기간을 즉시 판별할 수 있다:
  `(New-Object System.Security.Cryptography.X509Certificates.X509Certificate2("C:\GPKI\Certificate\class2\<이름>_sig.cer")).NotAfter`
  만료 시 갱신이 아니라 **재발급** 대상이다(다른 기기·매체에 유효본이 있으면 인증서
  복사가 더 빠르다). → 사례
