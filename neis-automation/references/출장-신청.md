# 출장 신청 — 개인출장관리

출장은 **복무 > 개인근무상황관리가 아니라 복무 > `개인출장관리`** 에서 신청한다.
근무상황 신청과 화면 구조가 비슷하지만 출장자 목록(동반자)과 여비 항목이 따로 있다.
상신 단계는 [상신-공통.md](상신-공통.md)를 함께 따른다.

1. **여비지급 여부부터 판단할 것(가장 중요).**
   **강사료·원고료·수당·자문료 등 사례금이 지급되는 출장(외부 강의, 자문·심의 회의 등)은
   학교 결재에서 무조건 여비 부지급**으로 올린다. 요청 기관이 사례금을 지급하므로 학교
   예산에서 여비를 이중으로 받지 않는다는 취지다. 접수 공문에 강사료·수당 표기가 있으면
   그것이 곧 부지급 근거이며, 사용자에게 되묻기 전에 부지급을 기본값으로 잡는다.
   - 반대로 사례금이 없는 협의회·연수·인솔 출장 등은 여비 지급이 기본이다.
   - `여비지급하지않음` 체크 시 *"여비부지급의 경우 에듀파인으로 연계되지 않습니다"*
     알림이 뜨는데 **정상**이다([확인]).
   - **검증 지점은 [승인요청] 후 기안내용 표의 `여비지급여부` 열**이다. `지급안함`이면 맞다
     (지급이면 `지급안함` 대신 `지급`). 상신 전 반드시 이 열을 확인할 것.
2. **선례 확보**([상신-공통.md](상신-공통.md) 「선례 확보」): 상신함에서 결재문서명에 `출장`을 넣고
   조회하면 과거 출장 신청이 모두 나온다. 문서명이 `출장신청-[국내출장(관내)]기간:…` 형태라
   관내/관외가 바로 구분되고, 완결 건 상세보기에서 결재선과 상신내용(출장인원·여비지급여부·
   여비지급기관)을 그대로 볼 수 있다.
   **관내와 관외는 결재권자가 다를 수 있으므로 같은 출장종류의 선례**를 볼 것.
3. **[신청]** → "출장신청" 다이얼로그. 기간정보 행 1개가 자동 생성된다(당일 08:30~16:30).
   - **출장종류를 먼저 확정**한다(국내출장(관내) / 국내출장(관외) / 국외출장 / 출장(연수)).
     화면 안내대로 **출장(연수)는 출장비가 지급되지 않는다.**
     〔공식 FAQ〕 출장(연수)는 근무시간 내 야간제·계절제 대학원 수강용으로 신설된 항목이며
     에듀파인으로 연계되지 않는다. 예외적으로 출장비 지급이 필요하면 근무지내(관내) 출장으로
     상신하라는 것이 공식 안내다.
   - 날짜는 **달력 아이콘**으로만(SKILL.md 일반 팁 「날짜 입력」). 시작일을 바꾸면 종료일이
     동기화되므로 시작 → 종료 순서.
   - 시·분은 커스텀 드롭다운이다(SKILL.md 일반 팁 「커스텀 드롭다운」).
     반영되면 신청시간이 `0일 3시간 20분`처럼 자동 계산된다.
4. **필수 텍스트 필드**(클릭 후 타이핑 정상): 연락처(숫자만 치면 `010-0000-0000`으로 정형),
   출장지, 출장목적. 이동사항은 선택. 저장 전 SKILL.md 일반 팁 「입력값 검증」의 JS 대조로 한글 깨짐을 점검한다.
5. **동반자(출장자 목록)**: [추가] → "출장자 선택" 팝업에서 성명으로 조회 → 행 체크 → [추가].
   - **동명이인이 흔하다.** 목록에 `성명(사용자ID)`로 표시되고 직급 열이 비어 있을 수 있으므로,
     둘 이상 나오면 **임의로 고르지 말고 사용자에게 어느 계정인지 확인**받는다.
   - 추가된 행은 `출장기간동일여부 = Y`로 대표자와 같은 기간이 적용된다. 그리드 가로 스크롤로
     종료 시각까지 눈으로 확인할 것.
6. **상신**([상신-공통.md](상신-공통.md)):
   1. **확인 ①**: 출장종류·기간·출장지·출장목적·동반자·여비지급여부를 사용자에게 요약해 확인받는다.
   2. **[승인요청]** → 기안문서상신 화면. 기안내용 표의 `여비지급여부`를 1번 기준으로 확인한다.
   3. 결재선은 **[결재자지정]에서 구분 라디오(검토/결재) → 이름 조회 → [▼]** 로 직접 조립하고
      같은 출장종류 선례의 결재선과 대조한다(「결재선 조립」).
   4. **확인 ②**: 결재선과 기안내용 표를 요약해 확인받는다.
   5. **[상신]** → "상신하겠습니까?" → 완료 알림.
7. **검증**: 개인출장관리 목록에 새 행이 뜨고 결재상태가 `상신(진행)`이 된다. 출장인원은
   동반자가 있으면 `○○○ 외 N 명`으로 표기된다. 상신함 상세보기에서 결재선·여비지급여부까지 확인.
8. **잘못 올렸으면 [회수] → [복사] → 수정 → 재상신**([상신-공통.md](상신-공통.md) 「6. 잘못 올린 건 되돌리기」·「7. 같은 내용으로 다시 올리기」).
   회수 후 결재상태는 `상신취소`가 되고 **행은 목록에 남아 총계에 합산**되므로,
   [복사]로 새로 올린 뒤 `상신취소` 행을 체크해 [삭제]한다.
   - **[복사]는 여비 설정까지 그대로 복제**하므로 바꿀 항목만 손대면 된다.
   - 이 화면의 삭제는 확인 창 없이 바로 "자료의 삭제가 완료되었습니다"가 뜨고
     Total이 즉시 준다(근무상황의 지연 알림과 다름). 그래도 [조회]로 재조회해 확인할 것.
   - **삭제 전 체크 행 확인 필수**: 같은 기간·같은 출장지 행이 나란히 놓이고, 직전 작업의
     체크가 남아 있을 수 있다. `결재상태` 열이 `상신취소`인 행만 잡혔는지 스크린샷으로 볼 것.
