# 정기고사 OMR 일괄채점

교무부 안내 기준 절차: OMR 리딩·업로드 완료 후 교과담임이 나이스에서 일괄채점.

1. **메뉴**: 상단 권한 탭 **교과담임** → 좌측 **정기시험** → **정기시험채점**
   (좌측 메뉴 구성: 문항정보표관리 / 정기시험학생답관리 / 정기시험채점 / 정기시험성적관리)
2. **조회 조건**: 학년도·학기·고사(기말고사)·학년·과목 설정 후 [조회].
   - 담당 과목이 하나면 고사 선택 시 과목이 자동 채워진다.
   - 조회 결과: 좌측에 강의실(반) 목록 + 반별 대상자 수가 표시된다.
3. **서답형 점수 소스 선택**: "학생답안 선택형 +" 드롭다운에서 **성적관리 서답형** 선택.
   - 옵션: 학생답안 서답형 / 성적관리 서답형 / 직전성적관리 서답형
   - 이 선택이 화면 재렌더링으로 "선택"으로 되돌아가는 경우가 있다.
     선택 후 zoom으로 표시값을 확인하고, 리셋됐으면 다시 선택할 것.
4. **강의실 전체 체크**: 목록 헤더의 전체선택 체크박스 클릭 → 담당 반이 모두 체크됐는지 확인.
5. **[일괄채점]** 클릭 → 확인 다이얼로그("선택한 반(들)에 대해서 일괄채점 하시겠습니까?") → [확인].
   - 확인 다이얼로그와 결과 알림("N 강의실 N건의 채점이 수행되었습니다" 반별 목록)은 늦게 뜬다
     (SKILL.md 일반 팁 「확인·완료 다이얼로그」). 채점 후 다른 조작 전에 반드시 결과 알림을
     확인하고 [확인]으로 닫을 것.
6. **검증**: 알림의 반별 채점 건수가 조회된 대상자 수와 일치하는지 대조.
   각 강의실 행을 클릭하면 우측에 "최종 채점일 : YYYY.MM.DD. HH:MM:SS"가 표시된다 (채점 전엔 "미채점").
   채점 완료 후 체크박스·드롭다운은 자동 리셋된다.
7. **주의**: 채점 후 정답 오류 등 문제 발견 시 임의 재채점 금지 — 반드시 평가계 문의 (교무부 지침).
