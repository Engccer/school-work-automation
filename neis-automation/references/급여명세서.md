# 급여명세서(지급명세서) 내려받기

특정 월 또는 여러 달의 급여명세서를 파일로 받는 절차. 조회 전용이라 되돌릴 위험이 없고,
같은 화면 구조가 연말정산·호봉 등 다른 급여 계열 리포트에도 그대로 적용된다.

1. **메뉴**: 좌측 **기본 메뉴 > 급여 > 급여 > 나의지급명세서**. 급여 아래가 [신청]과 [급여]
   두 갈래이고 명세서는 **[급여] 하위**에 있다. 권한 탭과 무관하게 항상 노출된다.
2. **급여지급월은 연-월 달력**이라 타이핑이 필요 없다. 달력 아이콘을 누르면 헤더에 연도,
   그 아래 1~12 월 그리드가 뜨고 **월을 한 번 클릭하면 그대로 입력된다**(다른 화면의
   날짜 필드처럼 세그먼트 조작을 할 필요가 없다). 연도 이동은 헤더 좌우 화살표.
3. **월을 바꾸면 급여구분이 자동으로 채워진다.** 급여작업이 끝나지 않은 당월을 열면
   `급여작업없음`이고, 지난달을 고르면 `월급여(AA)`로 바뀐다. **`급여작업없음`인 채로 조회하면
   빈 결과가 나오므로**, 조회 직전에 급여구분 표시값을 확인한다. `제외수당포함`은 기본 체크.
4. **[조회]** → 리포트 뷰어(보통 2페이지)가 뜨고 상단에 이체은행·계좌·예금주가 함께 나온다.
   `지급명세서 조회 가능일자`에 숫자가 채워지면 정상 조회다.
5. **저장은 뷰어 툴바의 저장 아이콘**(인쇄 아이콘 왼쪽)이고, 형식은
   **PDF / DOC / XLS / XLS data / PPT** 다섯 가지다. **CSV는 없다** — CSV가 필요하면
   XLS로 받아 변환한다(아래 8번).
   - **네이티브 "다른 이름으로 저장" 창이 뜨지 않고 즉시 다운로드된다.** K-에듀파인 PC저장의
     4겹 창 구조와 전혀 다르므로 그쪽 절차를 끌어오지 말 것.
   - 저장된 **PDF는 텍스트 레이어가 정상이라 스크린 리더로 바로 읽힌다**(K-에듀파인 결재
     문서 PC저장 PDF가 깨지는 것과 대조된다). `pdftotext`로도 그대로 나온다.
6. **툴바 좌표는 페이지 스크롤에 따라 움직인다(함정).** 명세서 내용을 보려고 스크롤한 뒤
   이전 좌표로 저장 아이콘을 누르면 **아무 일도 일어나지 않는다**. → 사례
   저장 메뉴는 캔버스·iframe 안이라 **요소 찾기·접근성 트리 읽기에 잡히지 않으므로**, 누르기 직전
   스크린샷으로 툴바 위치를 다시 확인하는 것 외에 방법이 없다.
7. **여러 달을 받을 때가 이 작업의 핵심 함정이다.** XLS로 저장하면 실제 파일은 **.xlsx**이고
   이름이 `download-<난수>.xlsx`라 **어느 달인지 파일명에 남지 않는다.** 연속으로 받으면
   구분이 불가능해지므로 **한 달 받을 때마다 즉시 이름을 바꿔 목적지로 옮기고 다음 달로 넘어간다.**
   월 변경 → 조회 → 저장 → 이동을 한 묶음으로 돌린다.
8. **CSV·요약이 필요하면 받은 xlsx에서 스크립트로 만든다**(모델이 숫자를 옮겨 적지 않는다).
   **완성본은 스킬 루트에서 `python scripts/payslip_csv.py <xlsx> <csv>`** 다
   (의존성: openpyxl, 없으면 `pip install openpyxl`). CSV(UTF-8 BOM)는 **앞 3행이 메타**
   (`급여지급년월,YYYY-MM` / `성명,…` / 빈 행)이고 **4행부터 헤더 `구분,항목,금액,계산근거`**와
   항목·합계 행이 온다. 9번의 검산 4종을 출력하며, 하나라도 어긋나면 종료 코드 1이다.
   계산근거 표가 페이지를 넘어 두 덩어리로 나뉘어도 라벨로 합쳐진다(→ 사례). 시트 구조는 이렇다.
   - 상단: `급여지급년월 YYYY 년 MM 월   성명 …`이 **한 셀에 통째로** 들어 있어 정규식으로 판다.
   - `[세부내역]` 아래 헤더 행에 **급여내역 / 세금내역 / 공제내역이 가로로 병렬**이고, 그 아래
     행들이 세 블록을 동시에 담는다. **열 인덱스를 고정으로 가정하지 말 것** — 헤더 행에서 세
     이름의 열 위치를 찾아 구간으로 나눈 뒤, 각 구간에서 문자열은 라벨, 숫자는 금액으로 집는다
     (월마다 항목 수가 달라 레이아웃이 밀린다).
   - `실수령액`은 **라벨과 금액이 다른 구간에 걸쳐** 있어 위 규칙에 걸리지 않는다. 별도로 처리한다.
   - 아래쪽에 **계산근거 표**(항목·금액·산출 근거)가 따로 있어 라벨로 이어 붙일 수 있다.
9. **검증은 계산으로 한다.** 두 갈래이고 둘 다 통과해야 **월을 잘못 골랐거나 파싱이 새는 경우를
   함께 잡아낸다.**
   - **스크립트 자동 검산(4종, 하나라도 어긋나면 종료 코드 1)**: 항목별 합계 = **급여총액·세금총액·
     공제총액**(3종), **급여총액 − 세금총액 − 공제총액 = 실수령액**(1종).
   - **사람이 대조할 것**: 스크립트가 마지막 줄에 출력하는 `ym`(시트의 `급여지급년월`)이 파일명·
     조회월과 같은지. 스크립트는 이 대조를 종료 코드에 반영하지 않으므로 종료 코드 0만으로 월
     확인이 끝난 것이 아니다.
10. **금액 해석 시 알아둘 것**: 연말정산 환급은 **공제 항목에 음수**로 들어온다(정산 월).
    그 달만 공제총액이 뚝 떨어지고 실수령액이 크게 늘어나는데 **오류가 아니다.** 정근수당이
    붙는 달도 같은 이유로 튄다. 월별 편차를 보고할 때는 이런 원인 항목을 데이터에서 찾아
    함께 제시한다(추측으로 원인을 쓰지 말 것). → 사례
11. **개인정보 취급**: 명세서에는 계좌번호·주민 관련 정보·급여액이 들어 있고, 생성 CSV에도
    성명이 들어간다. 화면 스크린샷은 디스크에 저장하지 않고(SKILL.md 일반 원칙), 파일은 사용자가
    지정한 위치에만 둔다.
    지정이 없으면 학교 공유 폴더에 임의로 넣지 말고 사용자에게 위치를 확인한다.
