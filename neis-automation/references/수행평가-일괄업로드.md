# 수행평가 성적 일괄업로드 · 강의실별 일람표 출력

수행평가 점수를 학생마다 화면에 치지 않고 **나이스 양식 CSV를 내려받아 채운 뒤 올리는** 절차와,
마감 전에 교무부에 내는 **강의실별 일람표(전체영역)** 출력까지 다룬다. Playwright 경로에서 끝까지
검증했다(→ 사례).

- **입력 메뉴**: 교과담임 → 수행평가 → **수행평가성적관리**
- **출력 메뉴**: 교과담임 → 수행평가조회/통계 → **수행평가조회** → 상단 탭 **강의실별일람표조회-전체영역**
- [마감]은 이 절차에 넣지 않는다. 사용자가 따로 요청할 때만 누른다.

## 0. 착수 전 판단

1. **미응시·장기결석 처리를 평가계획 원문에서 확인한다.** 한 문서 안에서도 규정이 엇갈리는 경우가
   있다(학년 비고·공통 유의점은 "최하점의 차하점", 영역별 채점기준표는 "미응시 0점" 등). 엇갈리면
   사용자에게 보여 주고 학생별 처리를 확정받는다. 미인정 장기결석은 대개 0점 조항이 따로 있다.
2. **수행평가에서는 결시를 고르지 않는다(원칙적 금지).** 미응시·장기결석 학생도 결시명칭
   (인정결·질병결·미인정결·기타결)은 비워 두고 **평가계획에 따른 점수(0점, 최하점의 차하점 등)를
   넣는다.** 화면 안내문에 "미응시자는 [결시] 또는 학적변동 처리"라고 적혀 있어도 따르지 않는다.
   결시명칭을 넣으면 그 학생에게는 점수가 들어가지 않는다(`결시생은 점수를 입력하실 수 없습니다`).
   결시명칭 칸은 누르지 않는다. 이미 결시가 들어간 학생이 보이면 고치기 전에 사용자에게 알린다. → 사례
3. **전출·전입 등은 `영역별 학적변동` 칸으로 처리한다**(결시가 아니다). 선택지는 입학·재입학·
   편입학·전입학·전출·면제·유예·취학·재취학. 전입생이 이 학교에서 응시했으면 인정점이 필요 없다.
4. **명렬이 정본과 다를 수 있다.**
   - 외국인 학생은 나이스에 영문 성명으로 올라가 있어 정본(한글 표기)과 이름이 다르다. **반·번호로
     맞추고 성명 차이는 경고로만** 남긴다.
   - 정원외관리 학생은 양식에 행이 없다. 정본에만 있는 학생은 오류가 아니라 참고로 보고한다.

## 1. 양식 CSV 내려받기

1. 수행평가성적관리에서 학년도·학기·학년·과목·**영역**·**강의실**을 고르고 [조회](드롭다운은 커스텀 DIV).
2. 그리드 위 **[일괄파일업로드]** → 팝업에서 **[엑셀다운로드]** → 형식 라디오에서 **CSV** → [확인].
   `run_code`에서 `page.waitForEvent('download')`를 클릭 전에 걸고 `saveAs`로 작업 폴더의 `양식/`에 둔다.
   영역 × 강의실마다 한 파일이다.
3. 팝업은 우상단 ×로 닫는다. 다음 영역·강의실은 뒤 화면에서 조건을 바꿔 [조회]한 뒤 다시 연다
   (팝업 위로는 뒤 화면 드롭다운을 못 바꾼다).

## 2. 양식 채우기 (스크립트)

양식 형식을 **그대로** 지켜야 업로드가 받아 준다.

- **UTF-8 BOM, CRLF, 모든 칸 큰따옴표.** Python이면 `encoding="utf-8-sig"` +
  `csv.writer(f, quoting=csv.QUOTE_ALL, lineterminator="\r\n")`.
- 열: 과목·영역·반·번호·성명·선택형·서답형·기타·기타2·합계. **점수는 `합계` 칸만** 채운다.
- 빈칸 = 점수 없음(학적변동 학생). 0점은 `0`을 쓴다.
- 스크립트가 할 검증: 양식 행과 정본 행이 반·번호로 1:1 대응, 점수 범위(0~만점), **급간**(받아쓰기
  0.5점 단위 같은 평가계획 단위), 특례 학생(학적변동·장기결석)은 코드 안 표로 명시. 문제가 하나라도
  있으면 종료 코드를 0이 아니게 해 업로드 전에 멈춘다.

## 3. 올리기

1. 해당 영역·강의실로 [조회] → [일괄파일업로드] → **[일괄업로드]**를 누르면 파일 선택 창이 뜬다.
2. **Playwright에서는 파일 선택 창이 MCP 대기 상태가 된다**(playwright.md 「파일 선택 창」). 클릭하는
   `run_code`는 거기서 끝내고, `browser_file_upload`로 그 영역·강의실 파일 하나를 넣는다.
3. 별도 호출로 팝업의 미리보기를 읽어 **팝업 제목의 영역·강의실**과 **행마다 번호·합계**가 올릴 파일과
   같은지 대조한다.
4. 맞으면 팝업 **[저장]** → `저장하시겠습니까?` [확인] → `자료의 저장이 완료되었습니다.` [확인].
   확인 창은 늦게 뜬다(일반 팁 「확인·완료 다이얼로그」).
5. 학적변동은 뒤 화면 그리드의 `영역별 학적변동` 칸 드롭다운에서 고르고 **화면 [저장]**한다.
   저장 뒤 상단 요약의 학적변동 수가 늘었는지 본다.

## 4. 검증

- 영역·강의실마다 **양식을 다시 내려받아 작성본과 한 줄씩 비교**한다(합계 칸 기준, 차이 0건이어야 한다).
  재조회 화면보다 확실하고, 개인정보가 담긴 이 사본은 스크래치 폴더에 받는다.
- 결시가 하나도 없는지도 본다. 일람표 PDF 텍스트에 `결`이 들어간 칸이 없어야 하고, `전출` 같은
  학적변동 표기만 있어야 한다(5절).

## 5. 강의실별 일람표 출력

1. 수행평가조회 → **강의실별일람표조회-전체영역** 탭. 학년도·학기·**학년**·과목·**강의실**
   (학년 기본값이 1이라 꼭 바꾼다) → [조회].
2. 결과는 **리포트 뷰어 팝업**으로 뜬다(10초 남짓). 한 강의실이 한 장이고, 같은 과목을 나눠 맡은
   교사의 영역까지 전체 영역과 합계가 함께 나온다.
3. 툴바 저장 아이콘 → PDF·DOC·XLS·XLS data·PPT·HWP. 제출용은 **PDF**. `waitForEvent('download')` +
   `saveAs`로 받는다. **같은 뷰어에서 한 형식을 받은 직후 바로 메뉴를 다시 열면 두 번째 다운로드가
   나오지 않는다** · 두 형식이 필요하면 사이에 몇 초 두고 메뉴가 열렸는지 확인한다. → 사례
4. 다음 강의실은 뷰어 [닫기] → 강의실 드롭다운 → [조회]를 되풀이한다.
5. **받은 PDF는 텍스트 레이어가 살아 있다.** 정기시험 통계 리포트(캔버스, 추출 불가)와 달리 PyMuPDF
   (`fitz`)로 읽혀 작성본과 자동 대조할 수 있다. 셀이 한 줄씩 나오고 `반/번호` 다음에 숨은 값 한 칸이
   끼므로 `반/번호` 줄을 기준으로 끊어 읽는다. 학적변동 학생은 해당 영역 숫자가 빠진다.
6. **급간·최저점 확인**(교무부 안내의 제출 전 점검): 영역별로 점수가 평가계획 단위로만 있는지, 0점이
   미응시·장기결석 학생에게만 있는지, "성실 참여 시 최저 N점" 같은 조항이 지켜졌는지 본다. 응시했는데
   0점인 학생은 채점기준표에 그 칸이 있는지 확인해 사용자에게 알린다.
7. 인쇄·서명·날인·제출은 사용자 몫이다.
