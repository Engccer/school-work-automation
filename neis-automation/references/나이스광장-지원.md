# 나이스광장 질의등록·업무 FAQ

## 나이스광장 질의등록 (help.neis.go.kr)

나이스·업무포털·EVPN 문제의 공식 온라인 신고 창구다(eVPN 사이트 자체에는 게시판이 없다).
- 진입: 업무포털 상단 **[나이스광장]** → 새 탭 → 우상단 **[질의등록]**. 업무포털 세션으로 SSO.
- 드롭다운을 처음 누르면 **유사질의검색 안내**가 뜨고([질의등록]으로 넘김), 이어서
  **개인정보 수집·이용 동의** 팝업이 뜬다(필수: 소속·성명·연락처 또는 휴대전화, 보존 3년).
  동의는 사용자 확인을 받고 라디오 `위의 내용에 동의함`을 누른다.
- 휴대폰번호는 **나이스 프로필 값이 미리 채워지는데 최신이 아닐 수 있다** — 사용자에게 받은 값으로 덮어쓴다.
- 업무구분 4단은 커스텀 드롭다운이다. **eVPN 전용 분류가 없어** `업무포털 > 업무포털`로 넣는다.
  앞 단계를 바꾼 뒤 다음 단 목록이 옛 값으로 남아 있으면 바깥을 한 번 눌러 닫고 다시 연다.
  질의유형: 단순질의 / 오류사항 / 기능개선 / 분배내역 / 교육 / 기타.
- 제목·내용·전화 칸은 일반 input/textarea라 **네이티브 setter + input/change 이벤트로 넣어도
  유지된다**(긴 한글 본문을 CDP 타이핑하지 말 것). 넣은 뒤 원고와 완전 일치 비교.
- [저장] → "질의등록을 저장하겠습니까?" → 확인(SKILL.md 일반 팁 「확인·완료 다이얼로그」) →
  "질의등록 저장을 완료하였습니다" → 질의확인 목록으로 이동. 목록 첫 행에서 **질의번호(QN…)**를
  JS로 읽어 기록해 둔다.

## 나이스 업무 FAQ

- **나이스 업무 FAQ는 나이스광장 > 자료광장 > FAQ**. 대부분 유치원
  업무 대상이라 교사에게 유용한 것은 적고, 핵심은 **「복무FAQ」 게시물의 첨부
  「4세대 나이스 복무 주요 질의사항(FAQ)」 hwp**(KERIS, 주기적으로 갱신, 확인 시점 판 2025-09-03)다.
  질의 필드에 "복무FAQ"로 검색(등록일 범위 확장 필요). 업무 파일에 〔공식 FAQ〕로 표기한
  항목들이 이 문서 출처다. 자동화 함정: 이 화면의 텍스트 필드도 CDP 타이핑이 원복되므로
  요소 찾기로 ref를 잡아 폼 값 설정으로 넣고 Enter로 조회한다. → 사례
