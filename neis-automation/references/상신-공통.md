# 상신 공통 — 선례 확보·결재선 조립·되돌리기

근무상황·출장·외부강의 신고처럼 [승인요청] → 기안문서상신 화면을 거쳐 결재에 올리는 업무의
공통 절차다. 화면별 입력은 각 업무 파일에 있고, 여기에는 화면이 같은 부분만 둔다.
흐름: 1 선례 확보 → (업무 파일의 입력) → 2 확인 ① → [승인요청] → 3 결재선 조립 → 4 확인 ② → [상신]
→ 5 검증. 잘못 올렸으면 6 회수 → 7 [복사]로 재상신.

## 1. 선례 확보

- "지난번과 똑같이 올려 줘"가 대부분이고, **결재선은 직전 같은 유형 문서를 그대로 재현하는 것이
  가장 안전하다.** 입력에 앞서 선례부터 확보한다.
- **승인사항 > 상신함**에서 결재문서명에 유형명(근무상황 유형명, `출장`, `외부강의신고` 등)을 넣어
  조회하고, 최근 **완결** 건의 문서명 링크로 "상신함 상세보기"를 연다. 재사용할 값이 한 화면에 다
  나온다 — 결재선 표(`결재순번/구분/사용자ID/사용자명/직위`, 승인 일시 포함)와 상신내용.
- **"완결"과 "기결취소"를 반드시 구분**할 것. 취소된 건(결재 전에 회수한 건도 상신함에서는
  `기결취소`로 보인다)을 원본으로 삼으면 안 된다.
- 조회 방법(기간 프리셋·문서명 필터·DOM 일괄 추출)은 [상신함-결재내역.md](상신함-결재내역.md).

## 2. 확인 ① → [승인요청]

- 폼을 다 채우면 SKILL.md 일반 원칙 「상신 전 사용자 확인」의 **확인 ①**을 받은 뒤 [승인요청]을 누른다.
- [승인요청] → **기안문서상신** 화면으로 전환. 결재문서명은 자동으로 채워지고 하단 기안내용 표에
  신청 건이 실린다. *"화면 하단의 기안내용이 정상적으로 초기화하면 상신 버튼이 활성화됩니다"*
  안내대로 **로딩 완료 전 클릭은 무시**되므로, 버튼이 무반응이면 3~5초 뒤 재클릭한다
  (첫 클릭이 먹지 않는 것이 정상).

## 3. 결재선 조립

**기본은 [결재자지정]에서 직접 조립**하는 것이다.
1. 팝업 우측 상단 **구분 라디오(결재/검토/협조/공람)를 먼저 고른다** — 이후 추가하는
   사람의 구분이 된다.
2. `사용자명` 에 이름을 넣고 [조회] → 행 체크 → **[▼]** 로 아래 결재선 그리드에 추가.
3. 검토자를 다 넣은 뒤 라디오를 **결재**로 바꾸고 최종 결재자를 추가한다.
4. **[저장]** 을 누르면 기안문서상신 화면의 결재선 그리드에 그대로 반영된다
   (이 [저장]은 개인 결재선을 새로 만드는 것이 아니라 현재 기안에 적용하는 동작).

**보조 경로: 저장해 둔 결재선 [개인결재선] → [지정]**. 용도별 결재선(연수용, 출장·연가용,
부서 업무용, 육아시간용 등)을 미리 만들어 두었으면 쓸 수 있지만, 이 팝업은 **행 하이라이트와
실제로 로드되는 결재선이 어긋난다**(누른 행과 다른 결재선이 우측 패널에 뜬다. 더블클릭해도 같다).
- 결재선명이 아니라 **우측 패널에 표시된 결재자 목록을 보고 고른다.** 패널 표시도 재현이 일정하지
  않으므로 반복 클릭으로 씨름하지 말고, [지정]한 결과는 아래 검증(결재선 그리드)으로만 확정한다. → 사례
- **저장된 결재선과 원하는 조합이 다를 때**: 가장 가까운 결재선을 [지정]한 뒤,
  **기안문서상신 결재선 그리드에서 뺄 결재자 행을 체크하고 [삭제]** 하면 된다.
  결재순서는 자동 재부여된다(기안 0 → 검토 1 → 결재 2). 결재선을 새로 만들 필요 없다.
  [삭제] 알림도 늦게 뜨므로 "삭제하였습니다"를 닫은 뒤 [상신]할 것(그 전의 [상신] 클릭은 알림에 먹힌다).

**검증**: 어느 경로든 **기안문서상신 화면의 결재선 그리드**에서 선례 결재선과 대조한다. 여기가 진짜
검증 지점이고, 아직 [상신] 전이라 다시 지정하면 된다. 결재선 그리드에는 기안자(0번) 아래로
검토·결재자가 붙는다.

〔공식 FAQ〕 결재선관리에서 만든 결재선이 상신 화면에 안 나타나는 것은 화면 오류가
아니라, **업무승인담당자가 [업무승인관리 > 결재문서관리]에서 해당 결재문서의
결재우선순위를 기관결재선으로 설정해야 반영되는 구조**다. 개인이 못 고치는 설정이므로
반복되면 학교 업무승인담당자에게 요청한다.

## 4. 확인 ② → [상신]

- 결재선 그리드와 기안내용 표를 요약해 **확인 ②**를 받는다.
- **[상신]** → "상신하겠습니까?" → [확인] → "상신을 완료하였습니다." → [확인].
  **[상신] 직후 화면이 그대로여도 정상**이다. 확인 창이 늦게 뜨므로 SKILL.md 일반 팁
  「확인·완료 다이얼로그」대로 기다렸다가 재스크린샷한다.

## 5. 검증

- 다이얼로그가 닫히면 업무 목록(개인근무상황관리·개인출장관리·외부강의목록)이 갱신되고 새 행의
  **결재상태가 `상신(진행)`**이 된다. 화면별 확인 항목은 업무 파일에 있다.
- 상신함을 재조회하면(한 번에 안 뜨면 [조회]를 한 번 더) 새 행이 잡히고, 상세보기에서 결재선과
  상신내용을 최종 확인할 수 있다.

## 6. 잘못 올린 건 되돌리기 — [회수]와 [기결취소] 구분(중요)

6·7절(회수·[복사] 재상신)은 근무상황·출장에서 확인된 절차다. 외부강의 신고는 진행 중·완결 건의
목록 체크박스가 눌리지 않아([외부강의-현황.md](외부강의-현황.md) 5번) 목록에서 회수·복사할 수 없고,
회수·재상신 경로가 확인되지 않았다. 외부강의 신고를 고쳐야 하면 사용자에게 알리고 멈춘다.

두 버튼은 대상이 다르다. 어느 쪽이든 상대 결재자에게 흔적이 남는다.
- **아직 아무도 결재하지 않았으면 [회수]** 다. 상신함에서 진행상황 `상신(진행)`이고
  **현처리자가 첫 검토자**면 이 경우다. 상신함이든 업무 목록이든 대상 행을
  체크하고 [회수] → "선택한 N건을 회수하겠습니까?" → [확인] → "회수하였습니다."
  (확인 창·완료 알림 모두 늦게 뜬다. 목록은 자동 갱신되지 않으니 [조회]로 다시 읽을 것)
- 결재가 끝난(완결) 건을 되돌리는 것이 **[기결취소]** 이고, 이때는 `[기결취소기안]…`
  문서가 상신함에 별도로 남는다.
- 회수 후 상태: 상신함 진행상황 `기결취소`, 업무 목록 결재상태 `상신취소`.
  **행 자체는 목록에 남는다**(삭제 아님).

## 7. 같은 내용으로 다시 올리기 — [복사]

- 업무 목록에서 `상신취소` 행을 체크하고 **[복사]** → 수정 다이얼로그(근무상황은 "근무상황신청수정")가
  열리면서 **분류·기간·시각·연락처·사유·목적지 등 전 필드가 그대로 복사**된다. 바꿀 것만 고치고
  확인 ① → [승인요청] → (필요하면 결재선 조정) → 확인 ② → [상신]. 값을 다시 입력할 필요가 없다.
- **[복사]는 새 행을 만든다.** 원래 `상신취소` 행이 목록에 남아 화면 하단 **총계에 계속 합산**되므로
  (→ 사례), 재상신을 마치면 그 행을 체크하고 [삭제]하는 것까지가 절차다. 결재 이력은 상신함에 남으므로
  감사 근거는 사라지지 않는다. 확인 ①에서 이 삭제 계획도 함께 알린다.
- **`상신취소` 행 삭제**: 같은 기간·같은 유형의 행이 나란히 있고 직전 작업의 체크가 남아 있을 수
  있으므로, **체크 직후 `결재상태` 열을 확대 캡처로 확인해 `상신취소` 행만 잡혔는지 확인**한 뒤
  [삭제]한다. 삭제 뒤에는 **[조회]로 재조회**해 행이 사라지고 총계가 정정됐는지 본다.
  삭제 확인 창·알림의 순서는 화면마다 다르다(업무 파일 참조).
