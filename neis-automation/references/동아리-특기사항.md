# 동아리 특기사항 입력 — 학생부자료기록

동아리 부서원 전원의 특기사항을 학생부자료기록 그리드에 입력·저장하는 절차.

1. **메뉴**: 동아리담임 → 학생생활 > 창의적체험활동 → 동아리활동관리 → **학생부자료기록** 탭
   → 학년도·부서명 확인 후 [조회]. (탭·조회 버튼은 화면 로딩 중 클릭이 씹히므로
   반응 없으면 2~3초 후 재클릭)
2. **화면 구성**: 학생별 행에 이수시간 / 누가기록 이수시간 합계 / 특기사항(텍스트 영역) /
   글자수(Byte). 한도 1500Byte(한글 3Byte = 약 500자). 빈 셀도 기본 35Byte로 표시된다.
3. **[이수시간반영] 버튼**: "전체시간표에 등록된 시간과 학생 개인별 출결상황을 계산" —
   이수시간기준등록의 기준 시수와 출결을 조합해 학생별 이수시간을 채운다(장기결석자는
   자동 0). 창체부가 "이수시간반영 생략"을 안내한 경우 **누르지 말 것**. 방법만 알아두기.
4. **특기사항 셀 입력**: SKILL.md 일반 팁 「학생부 텍스트 그리드 편집」 순서를 따른다
   (더블클릭 → 캐럿 확인 → 별도 호출 `type` → Byte·본문 검증 → 중립 셀로 커밋).
   잘못 들어간 셀은 더블클릭 → 캐럿 확인 → 별도 호출로 ctrl+a → Delete로 비운 뒤 다시 입력한다.
5. **이 화면 고유 사항**:
   - **빈 셀에서 더블클릭 직후 ctrl+a**는 포커스를 이수시간(숫자 필드)으로 튕겨낸다.
     한글 타이핑은 숫자 필드에서 거부되어 데이터 손상은 없지만 입력이 사라진다.
   - 커밋용 중립 셀은 학년/반 등. **성명 클릭은 금지** — 누가기록 이력 조회 팝업이 열린다.
   - 부서원 전원을 넣으므로 **2~3명 입력마다 [저장]**으로 중간 저장할 것. 탭이 사라져도
     나이스 SSO 세션이 살아 있으면 `sen.neis.go.kr/jsp/main.jsp` 직접 이동으로 재진입 가능. → 사례
6. **저장**: [저장] 클릭 → "저장하시겠습니까?" 확인 창. 다이얼로그·완료 알림 모두 늦게 뜨고 좌표 클릭이
   먹히지 않는 경우가 많으니 SKILL.md 일반 팁 「확인·완료 다이얼로그」 순서로 누른다.
   "자료의 저장이 완료되었습니다" 알림까지 확인·닫은 뒤 [조회] 재실행으로 글자수(Byte)가
   유지되는지 최종 검증할 것.
