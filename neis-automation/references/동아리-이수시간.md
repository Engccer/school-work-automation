# 동아리 이수시간기준등록 확인

창체부 안내에 따라 동아리 이수시간(학기 기준 시수)이 나이스에 등록돼 있는지 확인·등록하는 절차.

1. **메뉴**: 상단 권한 탭 **동아리담임** → 드롭다운 **학생생활 > 창의적체험활동** → 좌측 **동아리활동관리**
2. **화면 구조**: 상단에 4단계 워크플로우 버튼이 가로로 배열된다 —
   [부서만들기] → [부서배정] → [이수시간기준등록] → [동아리활동관리].
   [동아리활동관리] 안에는 탭 4개(출석관리 / 학생부자료기록 / 누가기록 / 활동내역)가 있다.
3. **[이수시간기준등록]** 클릭 → 학년도·부서명·기간 설정 후 [조회].
   - **주의(중요)**: 조회 기간 종료일 기본값이 **오늘**이라, 아직 실시하지 않은
     미래 활동일이 목록에서 빠진다. 학기 말까지 보려면 종료일을 늘려서 조회할 것.
     날짜는 SKILL.md 일반 팁 「날짜 입력」(필드 우측 달력 아이콘)으로 바꾼다.
4. **목록 구조**: 시간표 일자 × 교시별로 행이 나열되고, 학년 열마다 체크박스가 있다.
   동아리 활동이 실시된 교시에 체크하면 그 교시가 이수시간 1시간으로 등록된다.
   체크된 행에는 담당교사명이 표시된다. "전체시간표 일자가 있어야 체크박스가 활성화"
   된다는 안내처럼, 시간표가 없는 일자·학년 조합은 "미등록"으로 표시되고 체크 불가.
5. **검증 방법**: 학년 열 헤더의 괄호 숫자(예: "N학년 (NN)")가 **체크된 교시 수 = 등록된
   이수시간 합계**다. 이 숫자를 운영계획표의 시수 합계와 대조하면 스크롤 없이 총량을
   검증할 수 있다. 상세 검증은 스크롤하며 체크된 일자·교시를 운영계획과 대조.
6. 변경했다면 [저장] 클릭. 이미 등록된 상태라면 아무 조작 없이 종료(임의 재저장 불필요).
