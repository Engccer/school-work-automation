# 원격(외부망) 접속 — EVPN

학교 외부(자택 등)에서 내부 업무 시스템에 접근하려면 교육청 원격업무지원시스템
(EVPN, SSL VPN, 서울은 `evpn.sen.go.kr`)을 거쳐야 한다. **나이스(sen.neis.go.kr)는 공인망에서도
서버가 응답하지만, 업무포털(sen.eduptl.kr)·K-에듀파인(klef.sen.go.kr)은 EVPN 연결 없이는 HTTP 응답
자체가 없다**(미연결 시 타임아웃). → 사례
타 시도는 `evpn.<교육청 도메인>` 형태다(강원 evpn.gwe.go.kr, 전남 evpn.jne.go.kr,
부산 evpn.pen.go.kr, 인천 evpn.ice.go.kr 등).

## 사전 신청 (나이스에서, 부서장 승인 필요 — 공식 매뉴얼 기준)

- 경로: 나이스 **[기본메뉴] > [원격업무지원서비스] > [원격업무지원서비스(eVPN)]** 에서 신청 →
  부서장 승인 후 사용 가능. (부서 담당자 대리·일괄 신청: [시스템관리] > [원격업무관리(일괄신청)])
- 신청 항목: 사용기간 / 접속그룹(업무포털) / **VPN 전용 비밀번호**(숫자+영문+특수문자 조합
  9자 이상, 아이디와 동일 불가) / 보안서약서 동의 / 요청사유.
- **사용기간 최대 6개월**, 접속 시 비밀번호 변경주기 3개월. **재신청 시 기존 신청 정보는
  삭제**되며, 사용기간 시작일자는 신청 당일로 설정해야 한다.
  사용기간 만료·비밀번호 분실 시에도 나이스에서 재신청한다.
- 기간이 만료됐는데 외부에 있어 나이스에 못 들어가는 경우: eVPN 메인의 **[원격업무 외부신청]**
  → 교육디지털원패스 로그인(교직원은 나이스 아이디로 회원가입 가능) → 클라우드 신청 화면 →
  부서장이 나이스에서 승인. 단 **부서 담당자가 결재선(결재문서명 `VPN사용자접속승인요청`)을
  나이스 결재선관리에 사전 등록하고 적용 대상자로 지정**해 둔 경우에만 가능.

## 접속 절차 (Windows, 클라이언트 설치된 PC 기준)

1. `https://evpn.sen.go.kr` 접속 → **웹 로그인** (나이스 ID + 신청 시 설정한 VPN 전용
   비밀번호). 로그인하면 상단에 [download] [Run VPN] 버튼이 생긴다.
   첫 이용 PC는 [download]로 AXGATE VPN Client를 설치한다.
2. **[Run VPN]** → 데스크톱에 AXGATE VPN Client 로그인 창이 뜬다(웹 로그인과 별개의
   2차 인증). 같은 ID·VPN 비밀번호로 클라이언트 로그인하면 터널이 연결된다.
   성공 시 창이 트레이로 들어가고, TAP 어댑터("TAP-Win32 Adapter V9")에 10.x 내부 IP가 붙는다.
3. 페이지 상단 상태 **Installed / Running / Connected 모두 Yes**가 되면
   업무포털·4세대 나이스·K-에듀파인 바로가기 링크로 진입한다.
- 비밀번호 입력(웹·클라이언트 모두)은 사용자가 직접 한다(자동화 금지 영역).

## 함정

- **연결 여부를 "10.x IP가 보이는지"로 판정하지 말 것.** 터널이 끊긴 뒤에도
  **다른 어댑터에 10.x 주소가 잔존**해, IP만 보면 연결된 것처럼 보인다. 판정은 두 가지로 한다. → 사례
  ```powershell
  Get-NetAdapter | Where-Object InterfaceDescription -like "TAP-Win32*" | Select-Object Name, Status
  Test-NetConnection sen.eduptl.kr -Port 443 -InformationLevel Quiet
  ```
  **TAP 어댑터 Status가 Up이고 포털 443이 True**여야 연결이다. 어느 어댑터에 10.x가 붙어
  있는지는 근거가 아니다.
- **작업 시작 전에 이 확인부터 한다.** 미연결 상태에서 업무포털로 `navigate`하면 도메인
  권한 문제와 구분되지 않는 무응답이 나와 엉뚱한 곳을 헤매게 된다.
- **터널이 오래 유지되지 않을 수 있다.** 끊기면 K-에듀파인 등이 다시 무응답이 되므로, 원격 작업 중
  응답이 사라지면 EVPN 재연결부터 확인한다(웹 재로그인 → [Run VPN] → 클라이언트 재로그인). → 사례
- **첫 화면의 "EVPN 프로그램 설치 관련 안내" 팝업이 투명 백드롭으로 전체 화면의 마우스
  클릭을 삼킨다.** 키보드 탐색은 영향 없음(스크린 리더 사용자는 무관). 자동화로 조작할 때는
  팝업 [닫기](`closePop()`)를 먼저 실행해야 다른 요소를 클릭할 수 있다.
- **페이지 버튼(LOGIN·Run VPN·Close 등)이 CDP 합성 클릭에 반응하지 않는다.**
  `javascript_tool`로 `element.click()`을 직접 호출해야 한다(버튼 id: `loginButton`,
  `runVpnBtn2`, `closeBtn` 등).
- **상태 표시 "Installed No"는 미설치 확정이 아니다.** 클라이언트가 설치돼 있어도 실행 중이
  아니면 No로 표시된다. `C:\ProgramData\AXGATE\AXGATE VPN Client\Bin\AxgateVpnClient.exe`를
  실행하면 Installed/Running이 Yes로 바뀐다. 단일 인스턴스라 재실행해도 창이 다시 뜨지 않으며,
  클라이언트 로그인 창은 웹의 [Run VPN]으로 호출하는 것이 확실하다.
- **Chrome 비밀번호 관리자 자동완성은 미리보기일 뿐** DOM 값은 빈 문자열이다. 필드가 채워져
  보여도 실제 사용자 제스처 없이는 로그인이 진행되지 않는다.
- **AXGATE VPN Client 로그인 창은 스크린리더로 단독 인증이 안 된다(확인 시점 버전 1.4.0.77).**
  인증서 비밀번호 입력란에 키보드 초점이 가지 않고 마우스로 찍어야만 들어간다(업무포털 인증서
  창은 정상). 스크린리더 사용자에게 EVPN 연결을 맡길 때는 이 단계에 마우스 조작이 필요하다는
  점을 미리 알린다. 버전이 바뀌면 재확인한다. → 사례

## 공식 매뉴얼과 FAQ 핵심

- **KERIS eVPN 사용자 메뉴얼(엑스게이트, PDF 약 65쪽)**: eVPN 페이지 **로그인 후**
  [매뉴얼 보기]로 다운로드된다(파일명 `manual.pdf`). 최초 접속·클라이언트
  다운로드/설치/연결/해제/패치 절차와 FAQ 수록. EVPN 문제 해결의 1차 참조.
- **「4세대 나이스 EVPN 접속방법」(hwp, 2023-07-24, KERIS)**: 나이스 상단 [사용자지원] →
  나이스광장 → 자료광장 > **사용자설명서** → 제목 **"EVPN"** 으로 검색(**"원격"으로는 안
  나온다**) → 상세에서 파일 체크 → [다운로드].
  - 등록일 조건 기본값이 최근 1개월이라 범위를 넓혀야 검색된다. 날짜는 SKILL.md 일반 팁
    「날짜 입력」의 단독 필드 방식(달력 아이콘 → 헤더(연월) 클릭 → ◀로 연 단위 이동).
  - 이 hwp는 hwp2hwpx 변환 시 하이퍼링크 필드 값에 NUL(0x00) 바이트가 그대로 실려
    hwpx-tomd가 XML 파싱 오류를 낸다(hwpx-tomd 이슈 등록. NUL을 제거하면 변환되나 스크린샷
    위주라 텍스트가 거의 없다). PDF를 우선 사용. → 사례
- **FAQ 핵심**(KERIS 매뉴얼 발췌): 접속 환경은 **크롬 115 이상 또는 Edge**(IE 미지원).
  - 다운로드·VPN 실행 버튼이 안 보임 → 로그인 후에만 표시(정상).
  - 클라이언트 설치 실패 → 백신 등 보안 프로그램 차단 확인·예외처리, 불가하면 수동 설치.
  - 웹 로그인은 되는데 연결이 No → 대표 에러별 조치: **무결성 체크 실패(설정값)** =
    브라우저 업데이트 / **0xc000007b** = `C:\Windows\SysWOW64`의 msvcr100·msvcp100·
    mfc100.dll을 정상 PC에서 복사 / **Error 1719** = cmd에서 `msiexec /unreg` 후
    `msiexec /regserver`, 재부팅 후 재설치 / **"VPN 서버 IP를 입력하세요"** = 재설치+재부팅 /
    **key error** = 페이지 새로고침 또는 클라이언트 재실행 /
    **"로그인을 재시도해 주십시오[X, Y]"** = PC·네트워크 복합 원인, 위 조치를 순차 시도.
