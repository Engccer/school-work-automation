# 학기 시작 선행작업 — 성취기준 / 수행평가영역 / 반영비율·만점

교무학기가 전환되면 교무부가 전 교과에 "성취기준관리 / 수행평가영역 관리 / 반영비율·만점
관리"를 안내한다. 셋은 **같은 좌측 메뉴 묶음에 순서대로 놓여 있고 앞 단계가 뒤 단계의
입력값이 되므로** 위에서 아래로 처리한다.

- **메뉴**: 교과담임 → **정기시험/수행평가선행작업** → 성취기준관리 / 수행평가영역관리 /
  반영비율·만점관리 / 성적파일올리기 / 성적파일관리.
  교무부 안내문의 "지필/수행 선행작업"이 이 메뉴다(화면 명칭과 다르므로 헤매지 말 것).
- 조회 조건은 세 화면 모두 학년도·학기·학년·과목이고 **드롭다운은 전부 커스텀 DIV**다
  (SKILL.md 일반 팁 「커스텀 드롭다운」).

## 0. 착수 전 판단 — 이 학년·과목이 등록 대상인가

**안내문의 "○학년 해당" 표기를 그대로 믿지 말고 평가계획의 배점 유무로 판단한다.**

- **자유학기제 등 배점 없이 등급(A~E)으로만 평가하는 학기는 수행평가영역 등록 대상이
  아니다.** 나이스에 넣을 점수가 없기 때문이다. 성취기준관리만 하면 된다.
- 같은 학년이라도 **지필+수행 점수제였던 직전 학기에는 영역이 등록돼 있다.** "지난 학기에
  있었으니 이번에도" 라고 단정하면 안 되는 지점 — 평가계획에 **점수(배점)와 반영비율이
  적혀 있는지**가 유일한 기준이다.
- **공동 담당 과목은 "동 학년 동 교과 담당 중 한 분만 입력"이 원칙**이다. 조회해서
  `Total 0`이면 아무도 안 한 것이지만, 대표로 넣을지는 **사용자에게 확인받고** 진행한다.
- **교무학기가 전환되면 학기 드롭다운에 현재 학기만 남는다.** 지난 학기 등록분을 조회해
  대조하려는 시도는 이 화면에서는 불가능하고, 아래 `[이전자료가져오기]`로만 볼 수 있다.

## 1. 성취기준관리

1. 조회 조건 설정 후 [조회] → `Total 0`이면 미등록.
2. **[가져오기] → [국가교육과정성취기준]** (다른 옵션: 이전자료 / 타학년자료).
3. 팝업 목록에서 **헤더 체크박스로 전체 선택** → **[가져오기]** →
   "저장하시겠습니까?" → [확인] → "저장이 완료되었습니다."
   즉 **[가져오기]가 곧 저장**이며, 영역별로 나눠 담을 필요 없이 한 번에 넣으면 된다.
4. **팝업의 `Total`은 성취기준 수가 아니라 성취기준 × 성취수준 단계 수다.** 저장 후
   목록의 `Total`이 실제 성취기준 수다. 이 둘을 혼동하지 말 것.
5. **학년마다 적용 교육과정이 달라 화면 구성이 바뀐다**(전환기에는 한 교사가 두 체계를
   동시에 다룬다).

   | 적용 교육과정 | 수준 열 이름 | 단계 | 팝업 Total |
   |---|---|---|---|
   | 2022 개정 | 성취수준 | A~E 5단계 | 성취기준 수 × 5 |
   | 2015 개정 | 평가기준 | 상·중·하 3단계 | 성취기준 수 × 3 |

6. 안내문의 마지막 단계인 **'성취수준(평가기준)관리' 탭**으로 옮겨 [조회]하면 단계별
   진술이 함께 들어온 것을 확인할 수 있다(위 표의 팝업 Total과 같은 건수).

## 2. 수행평가영역 관리

1. 조회 후 **[행추가]** → 한 행씩 **영역명 / 학기말 반영여부 / 학기말 반영비율(%) /
   영역만점**을 채운다. 마감여부·영역번호·기준등록여부는 저장 시 자동으로 붙는다.
2. **영역명은 그 학교의 표기 관행을 먼저 확인한다.** 안내문은 보통 "평가계획 안내
   가정통신문과 영역명 일치"를 요구하는데, 그 문서가 없어도 **[이전자료가져오기]로 지난
   학기 등록분을 조회하면 실제로 쓰인 표기를 그대로 볼 수 있다**(영역명·반영여부·비율·만점).
   과제명 뒤 영역 표기를 괄호로 붙였는지 뗐는지 같은 관행이 여기서 드러난다.
   - **이 팝업은 화면을 한 번 [조회]한 뒤에야 열린다.** 조회 전에 누르면 아무 반응이 없다.
   - 팝업에서 학년도와 **학기를 고르고 팝업 안 [조회]** 를 눌러야 목록이 나온다.
     학기 미선택 시 "학기는 필수입력 항목입니다".
   - 팝업 제목이 `주간 N학년 <과목>`이라 **어느 학년 자료를 보고 있는지 여기서 확인**한다.
     뒤 화면의 학년을 바꾸려면 팝업을 먼저 닫아야 한다(팝업 위로 열린 드롭다운은 안 먹는다).
   - 영역명이 다르면 **[가져오기]를 쓰지 말고 [닫기]** 한 뒤 직접 입력한다.
3. **입력 유실이 잦다. 다음 순서를 지킨다**(SKILL.md 일반 팁 「입력 유실」의 이 화면 사례).
   - **[행추가] 직후 같은 배치의 클릭+타이핑은 유실된다.** 행추가 → 대기 → **별도 호출**로
     셀 클릭 → 대기 → **또 별도 호출**로 타이핑.
   - **반영여부 드롭다운에서 O를 고른 직후의 첫 `triple_click` + `type`도 유실된다.**
     비율·만점은 넣고 나서 반드시 확대 캡처로 값을 확인하고, `0.00`이면 같은 조작을 한 번
     더 한다(두 번째는 대체로 들어간다).
4. **검증은 확대 캡처 스크린샷으로 한다.** 편집 그리드라 `aria-label` 전수 대조가 통하지 않는다
   (SKILL.md 일반 팁 「입력값 검증」).
5. **[저장]** → "저장하시겠습니까?" → [확인] → "저장이 완료되었습니다."
   확인 창이 늦게 뜬다(SKILL.md 일반 팁 「확인·완료 다이얼로그」, → 사례). 저장되면 **영역번호 1, 2, 3…이 자동 부여**되므로
   이것이 저장 성공의 즉시 신호다. 최종 검증은 [조회] 재실행.

## 3. 반영비율/만점관리 — 확인 + 지필 등록

이 화면은 안내문에서 "확인"만 요구하지만, **지필이 빠져 있으면 여기서 바로 등록**한다.
화면 유의사항에 적힌 대로 `[정기시험 과목관리 + 수행평가 영역관리]와 동일한 기능`이다.

1. 조회하면 과목명 / 평가구분 / 고사·영역명 / 마감여부 / 학기말 반영여부 / 반영비율(%) /
   과목·영역 만점이 나온다. **평가구분이 `수행평가`인 행만 있으면 지필 미등록**이다.
   (2번에서 넣은 수행평가 영역이 여기 자동으로 실린다)
2. 점검 항목은 두 가지다 — **지필 + 수행 반영비율 합이 100%인지**, **학기말 반영여부가
   전 행 O인지**.
3. 지필 등록: **[등록]** → "반영비율/만점등록" 팝업 → 한 행이 뜬다.
   - **평가구분**을 `정기시험`으로 두고 **고사명 드롭다운**에서 고사를 고른다.
     이 드롭다운은 화면 안내대로 *"해당 과목이 등록되지 않았고, 마감되지 않은 고사목록"*
     이라 이미 등록한 고사는 사라진다. 중간·기말이 다 보이면 **평가계획에 있는 고사만**
     넣는다(2학기 기말만 있는 학교가 흔하다).
   - **고사명을 고르면 학기말 반영여부가 자동으로 O**가 된다.
   - 반영비율(%)과 만점을 넣는다. 여기서도 **첫 `type`이 유실되므로 확대 캡처로 확인**하고
     비었으면 다시 넣는다.
   - 팝업 안 **[저장]** → "저장하시겠습니까?" → [확인] → "자료의 저장이 완료되었습니다."
     팝업이 닫히고 목록 `Total`이 1 늘어난다.
4. **최종 검증은 [조회] 재실행 후 반영비율 열의 합을 직접 더해 100%인지 본다.**
5. **평가계획 자체의 하자는 입력 대상이 아니라 보고 대상이다.** 예를 들어 지필에
   서·논술형 배점이 0으로 잡혀 있으면(직전 학기에는 있었는데 이번 학기에 빠진 경우 등)
   **계획서대로 입력하되, 최소 반영 비율 지침에 걸릴 수 있다는 점을 사용자에게 알린다.**
   임의로 비율을 바꿔 넣지 않는다.
