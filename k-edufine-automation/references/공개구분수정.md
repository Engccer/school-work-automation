## 10-13. 완료 문서의 대국민공개여부 수정

**비가역, 사용자 승인 후.** 되돌리기(undo) 기능이 없고 공개구분 변경 이력이 남는다. 원래
값으로 되돌릴 때도 같은 절차를 다시 밟고 `수정사유작성`을 또 거친다. 그래서 처음부터 본문을
확인하고, 바꿀 값(공개구분·근거 호)을 사용자에게 승인받은 뒤 저장한다. 특히 겸직허가처럼
본문에 개인 수익이 적힌 문서는 "본문에 개인정보 없음"에 해당하지 않는다.

기록물관리 점검 때 "비공개 문서를 공개·부분공개로 수정" 요청이 온다. 경로는
**문서등록대장 → 행 체크 → [수정▾] > [한건수정]**. 문서등록대장 조회 기간은 6개월 이하로
나눈다(기안.md 10-11). `WXSClient` 창 `문서수정`(`retrievePrdctnDocUpdtScrin.do`)이 뜨며
PrintWindow 캡처는 빈 화면이라 `mshtml_dom.ps1`로 다룬다.

- 상태 아이콘 `공`/`부`/`비`가 공개구분이다. WXSClient 창을 다룬 뒤 브라우저로 돌아와 하는 첫 클릭(행 체크 등)은 씹힐 수 있어 zoom으로 확인.
- 공개구분 radio `PUBLICATION0/1/2`(공개/부분공개/비공개, 값 1/2/3), 근거 checkbox `ho1`~`ho8`. 첨부 공개 radio는 disabled라 못 바꾼다.
- 저장 `fncCreate()`(setTimeout) → **`수정사유작성` 대화상자**(`othbcChngRsn` textarea, 확인 `fncVerify()`) → "정상적으로 저장되었습니다." Win32 메시지 창(버튼 id는 접수처리.md 8-6, 매번 덤프) → 창 자동 종료.
- 직원열람제한이 걸린 문서는 부분공개 클릭 때 안내 Win32 메시지 창이 먼저 뜬다(진행 무방, 버튼 id는 접수처리.md 8-6).
- 저장 전에 `문서번호 => <학교명>-NNNN`을 읽어 대상 문서인지 대조한다. 단 직원열람제한이 걸린 문서는 문서번호·발신명의 칸이 **빈 채로** 나온다. 그때는 직원열람제한 radio(`SECURITY*`)와 첨부 radio 개수(`modiAttachOthbcSe1..N`)로 목록의 문서와 맞춰 본다.
