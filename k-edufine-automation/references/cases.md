# 사례

규칙이 생긴 경위·날짜·변경 이력. 본문 규칙 끝의 `→ 사례`가 이 문서의 같은 제목 절을 가리킨다.

목차

- 개요: 원격(외부망) 접속 / 자동화 경계
- 2단계 / 6단계: 주입 JS 규칙
- 접수처리: 결재 문서 창 요소 (편철) / 8-2 과제카드 지정 / 8-3 지정 검증
- 기안: 핵심 원칙 / 10-5 / 10-8 / 10-10 / 10-11 / 10-11-1
- 한ODT: HwpODTpatch 무한 루프
- 기술노트: Win32 / PowerShell 함정
- 일반 원칙: 세션이 죽으면
- 변경 이력 (v5.3.0 ~ v1)

## 개요: 원격(외부망) 접속

- 2026-08-20 실측: EVPN 미연결 시 K-에듀파인은 타임아웃, 연결 시 302 응답.
- 원격 작업 중 터널이 약 12분 뒤 끊긴 사례가 있다.

## 개요: 자동화 경계

v1(2026-07-06)은 결재 문서 창을 "네이티브 창이라 제어 불가"로 적었다. v2(2026-08-10)에서
내부가 임베디드 IE(MSHTML)임을 확인해 틀린 기록으로 정정했다.

## 2단계: [K-에듀파인] 클릭 → 새 탭 진입

- v5.1(2026-09-21): 옛 기록의 "1568px 폭 기준 약 (407, 68)" 을 그대로 눌렀더니 바로 왼쪽의
  [나이스]가 열렸다. 창 폭에 따라 메뉴가 두 줄로 줄바꿈되기 때문이다. 이때부터 메뉴 좌표를
  기록하지 않고 `zoom` 확인을 원칙으로 삼았다.
- [연장] 버튼도 v3.1에서 "약 (218, 40), 1568px 폭 기준" 좌표로 9단계에 적혀 있었다. 같은
  이유로 2026-10-08 감사에서 좌표를 지우고 2단계로 옮겼다.

## 6단계: 주입 JS 규칙

v5.1(2026-09-21) 접수 공문 저장 때 v3 스니펫의 `'"C:\\\\some\\\\ascii\\\\path"'` 를 heredoc 으로
넣었다가 도구 계층에서 백슬래시가 한 겹 줄어 eval 이 `16진수가 필요합니다` 로 깨졌다. 패치
함수에 `try/catch` 가 없어 `__r` 이 미설정 → PowerShell 출력이 통째로 비어 원인을 찾는 데 한참
헤맸다. 이 일로 `String.fromCharCode(92)` 조립, `try/catch` + `__r`, JS 파일은 Write 도구,
패치와 실행 2단계 분리가 규칙이 됐다.

## 접수처리: 결재 문서 창 요소 (편철)

v2(2026-08-10)는 "과제카드 지정 UI 가 결재정보 탭에 없다"고 적었으나 오독이었다. v3에서
결재정보 탭의 `aChooseTkcrd` / `aCancelTkcrd` 앵커를 확인해 정정했다. `fncProcessDoc` 이
confirm 한 번으로 확정되는 비가역 동작이라는 v2 기록은 그대로 유효하다.

## 접수처리: 8-2 과제카드 지정

- 교육복지 계열 접수 공문의 편철 선례(`[선별적교육비지원] 교육급여및교육비지원`,
  보존 5년)는 2026-09 사용자 확인으로 정했다.
- 앵커가 부르는 함수 이름이 기록마다 `fncTkcrdChoisePop`(결재정보 탭 요소 표·편철 서술)과
  `fncChooseTkcrd()`(8-2 서술)로 달랐다. 어느 쪽이 맞는지 이 머신에서 확인할 수 없어,
  2026-10-08 감사에서 절차를 앵커 클릭으로 통일했다.

## 접수처리: 8-3 지정 검증

  이스케이프로 해석되고 eval 이 `16진수가 필요합니다` 로 깨진다. 더 나쁜 것은

  원인을 못 찾는다는 점. → `String.fromCharCode(92)` 조립 + `try/catch` + **패치와 실행을

  try/catch + `__r` 대입", "JS 파일은 heredoc 말고 파일 쓰기 도구로" 를 기술 노트에 승격.
  **폴더 선택 창이 이미 떠 버린 경우의 복구 경로를 실증** — v3 은 "띄우지 않는 것이 정답"
  이라고만 적었으나, 실제로는 `fncVerify()` 가 문서저장 모달과 "폴더 찾아보기" 를
  **동시에** 띄워 패치를 넣을 틈이 없다. 폴더창을 `dlg.ps1 -Click 2` 로 취소하면
  문서저장 모달은 살아 있고(`pMsg = 저장을 취소하였습니다.`) 그 상태에서 패치·실행하면
  정상 저장된다. 실무 흐름을 여섯 걸음으로 명시.

  PDF는 텍스트가 안 뽑힌다" 는 배포 저장에 한정된 얘기였다). `content.xml` 에서 문단
  경계를 보존해 추출하는 레시피와, **추출 결과를 터미널로 흘리면 한글이 깨져 '추출 실패'
  로 오판**하므로 UTF-8 파일로 쓸 것(나이스 스킬의 `pdftotext -enc UTF-8` 함정과 동종)을
  기록. 과제카드 검증은 `cardID` 존재가 아니라 **`cardName` 문자열**로 할 것 —
  정규식 기본값을 참으로 읽어 **미지정 문서를 지정됐다고 보고한 실수**가 있었다. 지정
  전/후 상태 비교 스니펫과 교육복지 계열의 편철 선례(`[선별적교육비지원]
  교육급여및교육비지원`)를 8-3 에 수록. 2단계의 **메뉴 좌표 기록을 삭제** — 창 폭에 따라
  `[K-에듀파인]` 이 두 줄로 줄바꿈되어, 옛 좌표 `(407, 68)` 을 누르면 **[나이스]가 열린다**

  창이 떠 있어도 exit 1** 로 실패하므로 `PowerShell` 도구를 쓸 것도 추가.
