# 컴시간 시간표

> **적용 범위**: 컴시간알리미 학생용 시간표(`comci.net:4082/st`)를 쓰는 중학교 한 곳에서 실사용으로 검증했다.
> 학교마다 학급 수와 표 구성이 다를 수 있으니 처음에는 `--dump`로 원자료를 저장해 결과와 대조한다.

컴시간알리미(`http://comci.net:4082/st`)의 학교 시간표를 읽어 **내 수업과 변동**만 뽑는다.

## 왜 브라우저인가

컴시간알리미는 공식 API가 없고 내부 데이터 응답은 암호화되어 있다. 운영사가 둔 장치이므로
**암호를 풀어 재현하지 않는다.** 대신 화면 없는 Edge로 사이트를 사람이 보는 것과 같이 열어 표를 읽는다(셸 명령 하나, 창은 뜨지 않음).
본인 학교만 조회하고, 하루 한두 번과 수업 직전 확인 정도로만 부른다.

나이스 교육정보 개방포털 시간표 API는 공식이지만 당일 변경이 늦게 반영되고 교사 이름이 없어 이 용도에 맞지 않는다.

## 설정

학교와 교사는 스킬 파일에 적지 않고 인자나 환경 변수로 준다. 자동 실행에 붙이려면 Windows 사용자 환경 변수로 등록한다.

| 인자 | 환경 변수 | 뜻 |
|---|---|---|
| `--school` | `COMCI_SCHOOL` | 학교 검색어(예: `가상중`). 필수 |
| `--school-full` | `COMCI_SCHOOL_FULL` | 검색 결과에 나오는 학교 이름(예: `가상중학교`). 없으면 검색어를 쓴다 |
| `--region` | `COMCI_REGION` | 같은 이름 학교를 가를 지역(예: `서울`). 없으면 첫 결과를 쓴다 |
| `--teacher` | `COMCI_TEACHER` | 교사 이름. 필수 |
| `--memo` | `COMCI_MEMO` | 정규 시간표 파일. 없으면 정규 시간표와 비교하지 않는다 |
| `--calendar` | `COMCI_CALENDAR` | 학사일정 CSV(`날짜`·`주요 일정`·`비고` 열). 없으면 일정 메모를 생략한다 |

파일 경로의 `{학년도}`는 조회 날짜의 학년도로 바뀌고, 상대 경로는 현재 폴더 기준이다. Python 패키지 `playwright`와 Microsoft Edge가 필요하다.

## 사용(스킬 루트에서)

```bash
PYTHONIOENCODING=utf-8 python scripts/comci.py                     # 오늘
PYTHONIOENCODING=utf-8 python scripts/comci.py --date 11-18        # 특정 날짜(YYYY-MM-DD도 가능)
PYTHONIOENCODING=utf-8 python scripts/comci.py --week              # 그 주 월~금
PYTHONIOENCODING=utf-8 python scripts/comci.py --out "<폴더>"       # <날짜>(<요일>) 컴시간 시간표.txt 저장
PYTHONIOENCODING=utf-8 python scripts/comci.py --all-changes       # 학교 전체 변경 칸까지 나열
```

- 조회는 그 주의 모든 학급을 훑어 약 15초 걸린다.
- **조회 가능한 날은 이번 주와 다음 주뿐이다**(사이트 `#nal` 선택지). 범위 밖이면 종료 코드 3.
- 주말은 `SKIP`. 종료 코드 0 정상, 1 조회 실패(네트워크·사이트 구조 변경), 2 입력 오류(학교·교사 미지정·없는 날짜), 3 범위 밖.
- `--date`의 월-일(`01-04`)은 오늘과 가장 가까운 해로 붙인다. 12월 말에 다음 주 1월 날짜를 넣어도 다음 해로 잡힌다.
- 정규 시간표 파일·학사일정은 UTF-8을 먼저, 안 되면 CP949로 읽는다. 둘 다 못 읽으면 `WARN` 한 줄을 내고 그 비교만 건너뛴다.
- 출력 파일은 1. 내 수업(장소·`(변경)` 표시) 2. 정규 시간표와 다른 점 3. 학교 전체 변경 칸 수(학년별) 순이다.
  학사일정 CSV에 그날 일정이 있으면 머리에 적는다. 전 학급이 빈 날은 "휴업일·고사일 등"으로 적고 비교하지 않는다.
  한 학년만 전 학급이 빈 날(그 학년 고사일 등)은 그 사실을 적고, 그 학년 수업은 "빠진 수업"과 따로 "시간표가 비어 없어진 수업"으로 적는다.

## 읽는 방법과 근거(실측 2026-11-16)

- 학교 검색: `#sc`에 학교 검색어 → [검색] → 지역이 맞는 행의 학교 이름 링크(`sc_disp(<학교 번호>)`). 같은 이름이 다른 지역에도 있을 수 있어 지역으로 거른다.
- 주 선택 `#nal`(값 1·2, 글자 `26-11-16 ~ 26-11-21`), 학급 선택 `#ba`(`1-1` 꼴). 학급마다 `제 N 학년 N 반 시간표` 표를 읽는다.
  주를 바꾼 직후 지난주 표가 남아 있을 수 있어, 학급 제목과 함께 표 머리에 원하는 날짜 칸(`월(30)`)이 보일 때까지 기다린다.
- **교사 이름은 가운데가 가려진다**(`홍길동` → `홍*동`). 교사별 보기가 없어 전 학급에서 가린 이름이 같은 칸을 모은다.
  같은 학교에 가린 이름이 같은 교사가 생기면 과목으로 한 번 더 확인해야 한다.
- **바뀐 칸은 `td` 클래스가 `변경`**, 평소 칸은 `내용`. 원래 수업이 빠진 것은 표에 흔적이 없으므로 정규 시간표와 대조한다.
- 정규 시간표는 `--memo`로 준 텍스트 파일의 `# …시간표` 절(요일 한 글자 줄 + `  <교시> <학년><반 두 자리>`, `---`에서 끝)이다.
  학기가 바뀌어 시간표가 바뀌면 이 절을 고친다.
- 학사일정은 `--calendar`로 준 CSV에서 그날 행을 찾는다.
- 페이지의 `수정일:` 값(시간표 마지막 수정 시각)을 출처 줄에 적는다.
- Playwright 번들 chromium은 설치 버전이 맞지 않아 실패했고 `channel="msedge"`(설치된 Edge)로 돈다.

## 자동 실행

같은 번들의 `alimjang-automation`을 함께 설치했다면 그 `run_daily.ps1`(작업 스케줄러 `알림장 일일 정리`, 평일 아침)이 전달사항 저장 직후 이 스크립트를
`--date <오늘> --out <알림장 날짜 폴더>`로 부른다. 결과는 알림장 날짜 폴더의 `<날짜>(<요일>) 컴시간 시간표.txt`다. 작업 스케줄러가 읽도록 위 환경 변수를 사용자 환경 변수로 등록해 두고, 파일 경로는 절대 경로로 적는다. 학교·교사를 등록하지 않았으면 시간표 단계는 건너뛴다.

- 전달사항이 없는 날(폴더가 안 생기는 날)은 시간표도 저장하지 않는다.
- 시간표 조회가 실패해도 알림장 처리는 계속되고 종료 코드에 넣지 않는다. 로그 `%LOCALAPPDATA%\알림장-자동화\log\<날짜>.log`의 `comci:` 줄을 본다.
- 아침 조회 뒤에 시간표가 또 바뀔 수 있다. 수업 직전에는 다시 조회한다.

## 보고

요청에 답할 때는 내 수업, 새로 생긴·빠진 수업, 학사일정 메모를 말하고 날짜에 요일을 붙인다. 변경 칸이 많은 날(요일 변동 등)은
`--all-changes`로 내 수업 반의 변동을 함께 짚는다.

## 시험

`PYTHONIOENCODING=utf-8 python -m unittest discover -s scripts/tests`(가짜 표만 쓰고 네트워크에 닿지 않는다).
점검용으로 `--dump <json>`으로 원자료를 저장하고 `--from-json <json>`으로 조회 없이 다시 분석할 수 있다.
